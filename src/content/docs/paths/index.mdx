已经会 Python，学 TypeScript 不需要从头开始。四条路径按"先建立语言感 → 再逐项迁移心智模型 → 最后补工程实践"排列，课时短，可以一节课一节课地推进。

<HomePaths />

## 适合谁

- **Python 开发者**：已有编程基础，想系统迁移到 TypeScript
- **面试准备者**：需要在短时间内掌握 TS 核心差异与实战
- **项目负责人**：团队从 Python 迁移到 TS，需要标准化学习路径
- **全栈工程师**：需要在 Node.js/前端项目中使用 TypeScript

## 怎么用

1. **自测定位**：先看"该从哪条开始"，按当前水平选起点
2. **按序学习**：每条路径内部已按教学顺序排列，建议依次完成
3. **即学即练**：每节课后做[自测清单](../practice/)，再刷对应[算法题](../algorithms/)
4. **碎片查阅**：遇到语法卡顿，去[手册](../handbook/)查对照表

## 该从哪条开始

- **完全没写过 TypeScript**：从[准备路径](preparation/)开始，先看清楚它和 JavaScript 的关系，再搭环境。
- **已经能写一点 TS，但写不踏实**：直接进[基础路径](foundation/)，把变量、函数、类型补齐。
- **TS 能跑，但总在和类型系统较劲**：[迁移路径](migration/)是为你准备的，逐项对照 Python 的习惯写法。
- **准备面试或上真实项目**：[进阶路径](advanced/)覆盖泛型、装饰器、设计模式与 Node.js。

## 下一步

- **先做自测**：去[练习与自测](../practice/)按路径做自测清单
- **再刷算法**：去[算法题库](../algorithms/)按难度/标签筛选练手
- **再做测验**：去[编程测验](../practice/quiz/)按模块验证掌握度

:::tip
建议"学一节、测一节、练一道"的节奏推进，不要攒着一次性测验。
:::
