适合已经有 Python 开发经验，希望系统迁移到 TypeScript 的工程师。

## 适合谁

- **Python 后端工程师**：熟悉 Django/FastAPI，要写 TS 微服务或前端配合
- **数据/ML 工程师**：要把 Python 脚本迁移到 TS/Node.js 生产环境
- **全栈开发者**：前后端统一 TS 栈，需补齐类型系统差异
- **面试冲刺者**：需快速掌握 TS 与 Python 核心差异点

## 怎么用

1. **按序迁移**：7 节课按"类型系统 → 函数 → 模块 → 异步 → 错误 → 枚举 → 字符串"依赖顺序
2. **对比迁移**：每节课含双语对照、迁移陷阱对比、自测清单，学完即测
3. **手动改写**：每节课把 Python 示例手动改写为 TS，强化迁移肌肉记忆
4. **对照手册**：卡住时去 [手册](../../handbook/cheat-sheet/) 查语法对照表

## 学完能做什么
- ✓ 熟练使用 TS 静态类型系统（联合/交叉/字面量/条件类型）
- ✓ 编写类型安全的函数签名（默认/剩余/对象参数/重载）
- ✓ 用 ESM 组织模块、配置 tsconfig、管理 npm 依赖
- ✓ 用 Promise/async-await 替代 asyncio，掌握并发与错误传播
- ✓ 用 try/catch、Error 子类、可选链/空值合并做健壮错误处理
- ✓ 在 TS 中用 enum/const/Union 替代 Python Enum/常量
- ✓ 用模板字符串、字符串方法、RegExp 做字符串处理
