适合刚开始学习编程，或从 Python 过渡到 TypeScript 的初学者。

## 适合谁

- **Python 入门者**：会基本语法（变量、循环、函数），想学静态类型
- **转行前端/全栈**：需要快速建立 TS 基础进项目
- **自学编程者**：想用 TS 养成类型思维的好习惯

## 怎么用

1. **按序学**：5 节课按依赖顺序排列，前一节是后一节的前置
2. **边学边练**：每节课内含双语对照、自测清单，学完即测
3. **动手跑**：去 [TS Playground](https://www.typescriptlang.org/play) 把对照代码跑通
4. **回头查**：卡住时去 [手册](../../handbook/cheat-sheet/) 查对照表

## 学完能做什么
- ✓ 编写带类型注解的基本 TypeScript 程序
- ✓ 使用 `let/const`、基本类型、联合类型
- ✓ 定义函数、箭头函数、可选/默认参数
- ✓ 写出 `if/else`、`switch`、`for/while` 等控制流
- ✓ 操作数组、对象、Map、Set 等数据结构
- ✓ 定义类、使用访问修饰符、实现继承与接口
- ✓ 为后续迁移路径打下坚实基础

## 下一步

- **去自测**：完成[练习与自测](../../practice/)中的基础部分
- **去刷题**：去[算法题库](../../algorithms/)按难度/标签筛选（如 `array`、`string`、`hash-table`）
- **进迁移**：完成 5 节后进入[迁移路径](../migration/)逐项对照 Python

:::tip
建议"学一节、测一节、练一道"，不要把 5 节全学完再测——边学边验证效果最好。
