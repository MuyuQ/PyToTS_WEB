## 场景与问题

使用联合类型时，TypeScript 需要在运行时确定具体类型。类型守卫让编译器能在特定代码块内确定更具体的类型。

## Python 回顾

```python
from typing import Union

def process(value: Union[str, int, list]) -> None:
    # Python 使用 isinstance 进行类型检查
    if isinstance(value, str):
        # 在这里 value 是 str 类型
        print(f"String: {value.upper()}")
    elif isinstance(value, int):
        # 在这里 value 是 int 类型
        print(f"Number: {value * 2}")
    elif isinstance(value, list):
        # 在这里 value 是 list 类型
        print(f"List length: {len(value)}")

# 检查属性
class Animal:
    pass

class Dog(Animal):
    def bark(self):
        return "Woof!"

def make_sound(animal: Animal) -> str:
    if hasattr(animal, 'bark'):
        # 检查是否具有某个方法
        return animal.bark()
    return "Unknown sound"
```

## TypeScript 等价写法

```typescript
function process(value: string | number | string[]): void {
  // typeof 类型守卫
  if (typeof value === "string") {
    // 在这里 value 是 string 类型
    console.log(`String: ${value.toUpperCase()}`);
  } else if (typeof value === "number") {
    // 在这里 value 是 number 类型
    console.log(`Number: ${value * 2}`);
  } else {
    // 在这里 value 是 string[] 类型
    console.log(`List length: ${value.length}`);
  }
}

// instanceof 类型守卫
class Animal {
  move(): void {
    console.log("Moving...");
  }
}

class Dog extends Animal {
  bark(): string {
    return "Woof!";
  }
}

function makeSound(animal: Animal): string {
  if (animal instanceof Dog) {
    // 在这里 animal 是 Dog 类型
    return animal.bark();
  }
  return "Unknown sound";
}

// in 操作符类型守卫
interface Cat {
  meow(): string;
}

function interact(pet: Dog | Cat): string {
  if ("bark" in pet) {
    // 在这里 pet 是 Dog 类型
    return pet.bark();
  } else {
    // 在这里 pet 是 Cat 类型
    return pet.meow();
  }
}
```

## 差异与常见陷阱

### 1. 自定义类型守卫函数

```typescript
// 用户定义的类型守卫
interface Fish {
  swim(): void;
}

interface Bird {
  fly(): void;
}

// 类型谓词 isFish 告诉 TypeScript 返回值的含义
function isFish(pet: Fish | Bird): pet is Fish {
  return (pet as Fish).swim !== undefined;
}

function move(pet: Fish | Bird): void {
  if (isFish(pet)) {
    // 在这里 pet 是 Fish 类型
    pet.swim();
  } else {
    // 在这里 pet 是 Bird 类型
    pet.fly();
  }
}
```

### 2. 联合类型的穷尽检查

```typescript
type Shape =
  | { kind: "circle"; radius: number }
  | { kind: "square"; side: number }
  | { kind: "rectangle"; width: number; height: number };

function getArea(shape: Shape): number {
  switch (shape.kind) {
    case "circle":
      // shape 被收窄为 { kind: "circle", radius: number }
      return Math.PI * shape.radius ** 2;
    case "square":
      // shape 被收窄为 { kind: "square", side: number }
      return shape.side ** 2;
    case "rectangle":
      // shape 被收窄为 { kind: "rectangle", width: number, height: number }
      return shape.width * shape.height;
    default:
      // 穷尽检查 - 如果上面漏了 case，这里会报错
      const _exhaustiveCheck: never = shape;
      return _exhaustiveCheck;
  }
}
```

### 3. null 和 undefined 检查

```typescript
function processUser(user: User | null | undefined): string {
  // 简单检查
  if (user) {
    // user 是 User 类型（非 null 且非 undefined）
    return user.name;
  }
  return "Anonymous";
}

// 使用可选链和空值合并
function getUserName(user: User | null): string {
  return user?.name ?? "Anonymous";
}

// 使用 ! 非空断言（谨慎使用）
function getNameLength(user: User | null): number {
  if (user === null) {
    return 0;
  }
  // 这里 TypeScript 知道 user 不是 null
  // 但我们明确告诉编译器 user.name 一定存在
  return user.name!.length;
}
```

## 优势对比

| 特性       | Python       | TypeScript             |
| ---------- | ------------ | ---------------------- |
| 运行时检查 | `isinstance` | `typeof`, `instanceof` |
| 属性检查   | `hasattr`    | `in` 操作符            |
| 自定义守卫 | 手动实现     | `is` 类型谓词          |
| 穷尽检查   | 无           | `never` 类型           |
| 可选链     | Python 3.10+ | 原生支持               |
| 空值合并   | `or`         | `??`                   |

## 试试看

### 预测输出

下面代码会输出什么？先按 Python 里判断 `None` 的直觉猜，再看答案。

```typescript
function show(value: unknown): string {
  if (typeof value === "object" && value !== null) {
    return "object";
  }
  return typeof value === "string" ? value.toUpperCase() : "other";
}

console.log(show(null), show("ts"), show([]));
```

<details>
<summary>点击查看答案</summary>

输出：`other TS object`。

关键在 `typeof null === "object"`：这是 JavaScript 早期遗留行为，所以判断「是不是对象」必须补 `value !== null`。`show([])` 走对象分支（数组也是对象）；`show("ts")` 走字符串分支，被收窄成 `string` 后才能安全调用 `toUpperCase()`。

**Python 里会怎样、为什么会想错**：Python 判断空值用 `x is None`，`None` 是独立的 `NoneType`，不会和「是不是对象」混在一起。照搬这个直觉、只写 `typeof value === "object"` 而不排除 `null`，就会把空值误判成对象。

</details>

### 找错误

下面代码有一个错误，能找到吗？

```typescript
function isString(value: unknown): boolean {
  return typeof value === "string";
}

function upper(value: unknown): string {
  if (isString(value)) {
    return value.toUpperCase(); // 编译报错
  }
  return "";
}
```

<details>
<summary>点击查看答案</summary>

错误在 `isString` 的返回类型写了 `boolean`：`if` 分支里编译器只知道「这个函数返回真或假」，拿不到「`value` 是 string」这个信息，于是 `value.toUpperCase()` 仍报错。

改成类型谓词，把信息交给编译器：

```typescript
function isString(value: unknown): value is string {
  return typeof value === "string";
}
```

运行时还是同一个 `typeof` 判断，但 TypeScript 会在 `if` 成立的分支里把 `value` 收窄成 `string`。

**Python 里会怎样、为什么会想错**：Python 里 `isinstance(value, str)` 之后直接用 `value.upper()` 天经地义，因为类型是运行时的、检查完就「知道」了。TypeScript 的类型在编译期擦除，`typeof` 的判断结果不会自动流进类型系统，必须显式声明谓词编译器才认。

</details>

## 练习

将以下 Python 代码转换为 TypeScript：

```python
from typing import Union, Optional

class Circle:
    def __init__(self, radius: float):
        self.radius = radius

class Rectangle:
    def __init__(self, width: float, height: float):
        self.width = width
        self.height = height

def calculate_area(shape: Union[Circle, Rectangle, None]) -> Optional[float]:
    if shape is None:
        return None
    elif isinstance(shape, Circle):
        return 3.14159 * shape.radius ** 2
    elif isinstance(shape, Rectangle):
        return shape.width * shape.height
    return None
```

<details>
<summary>答案</summary>

```typescript
class Circle {
  constructor(public radius: number) {}
}

class Rectangle {
  constructor(
    public width: number,
    public height: number
  ) {}
}

// 使用自定义类型守卫
function isCircle(shape: Circle | Rectangle): shape is Circle {
  return shape instanceof Circle;
}

function calculateArea(shape: Circle | Rectangle | null): number | null {
  if (shape === null) {
    return null;
  } else if (isCircle(shape)) {
    return Math.PI * shape.radius ** 2;
  } else {
    // TypeScript 知道这里是 Rectangle
    return shape.width * shape.height;
  }
}

// 或者使用更简洁的写法
function calculateAreaV2(shape: Circle | Rectangle | null): number | null {
  if (!shape) return null;

  if (shape instanceof Circle) {
    return Math.PI * shape.radius ** 2;
  }

  // 穷尽检查
  if (shape instanceof Rectangle) {
    return shape.width * shape.height;
  }

  // 如果漏了情况，这行会报错
  const _exhaustiveCheck: never = shape;
  return _exhaustiveCheck;
}
```

</details>

## 面试追问

1. **`typeof` 和 `instanceof` 的区别？**
   - 答：`typeof` 用于原始类型（string, number, boolean），`instanceof` 用于对象类型检查原型链。

2. **什么是类型谓词（Type Predicate）？**
   - 答：`pet is Fish` 这种语法，告诉 TypeScript 如果函数返回 true，那么参数就是这个类型。

3. **穷尽检查（Exhaustiveness Checking）有什么用？**
   - 答：确保 switch 或 if-else 处理了所有可能的情况，如果漏了 case 会编译报错。
