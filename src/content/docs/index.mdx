## 双语对照是这一站的核心

不是"用 TypeScript 再写一遍教程"，而是把每个差异点摆在一起让你看。类型注解在 Python 里是建议，在 TypeScript 里是规则：

<CodeCompare
  caption={`同一个函数签名：Python 在运行时才发现键不存在，TypeScript 在编译期就拒绝这段代码。`}
  py={`def process_user(user: dict) -> str:
    return user["name"]  # 类型注解只是"建议"

process_user({"age": 25}) # 运行时才报 KeyError`}
  ts={`function processUser(user: { name: string }): string {
return user.name;
}

processUser({ age: 25 });
// ~~~~~ 编译期直接报错，根本跑不起来`}
/>

1. **顺着路径学**：准备 → 基础 → 迁移 → 进阶，课时短，适合通勤和工位间隙。

3. **学完立刻验证**：每节课末尾有练习与面试追问，全部路径走完后做一遍编程测验。
4. **面试前刷题库**：36 道题按难度分级，每题都有双语实现、复杂度分析和常见变体。
