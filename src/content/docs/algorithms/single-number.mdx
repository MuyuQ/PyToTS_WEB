## 问题描述

给定一个非空整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现一次的元素。要求线性时间复杂度，且不使用额外空间。

**示例 1**

```text
输入：nums = [2, 2, 1]
输出：1
解释：2 出现两次相互抵消，只剩 1。
```

**示例 2**

```text
输入：nums = [4, 1, 2, 1, 2]
输出：4
解释：1 和 2 各出现两次抵消，只剩 4。
```

**约束条件**

- `1 <= nums.length <= 3 * 10⁴`
- `-3 * 10⁴ <= nums[i] <= 3 * 10⁴`
- 除答案外每个元素恰好出现两次
- 题目保证恰好存在一个只出现一次的元素

**边界情况**：数组长度为 1 时答案即该元素；答案为 0 或负数时依然成立，因为异或与符号无关；大规模输入下仍只需常数额外空间。

## 暴力解与瓶颈

朴素想法是用哈希表计数：

```python
def single_number_brute(nums: list[int]) -> int:
    count: dict[int, int] = {}
    for num in nums:
        count[num] = count.get(num, 0) + 1
    for num, freq in count.items():
        if freq == 1:
            return num
    return -1
```

逻辑直白，但存了 n 个键，空间 O(n)，不满足题目要求。排序后扫描可把空间降下来，时间却升到 O(n log n)。瓶颈在于**计数结构保存了不需要的频率信息**，而题目只关心"出现奇偶性"。优化方向是寻找一种满足 `a ^ a = 0`、`a ^ 0 = a` 的运算，把抵消过程压缩到单个变量中。

## 思路分析

最优解对全数组做异或。异或满足交换律与结合律，出现两次的数无论位置如何都会配对成 0，最后剩下只出现一次的数。

以 `nums = [4, 1, 2, 1, 2]` 为例：

| 步骤 | `num` | 运算过程        | `result` |
| ---- | ----- | --------------- | -------- |
| 初始 | —     | `result = 0`    | `0`      |
| 1    | 4     | `0 ^ 4`         | `4`      |
| 2    | 1     | `4 ^ 1`         | `5`      |
| 3    | 2     | `5 ^ 2`         | `7`      |
| 4    | 1     | `7 ^ 1 = 4 ^ 2` | `6`      |
| 5    | 2     | `6 ^ 2`         | `4`      |

:::tip
关键细节是 `result` 初始化为 0：0 是异或的单位元，`a ^ 0 = a`，因此初始值不会污染答案。顺序不影响结果，这正是交换律与结合律的直接应用。
:::

## 复杂度分析

| 解法         | 时间复杂度 | 空间复杂度 | 说明                         |
| ------------ | ---------- | ---------- | ---------------------------- |
| 哈希表计数   | O(n)       | O(n)       | 两次遍历，直观但空间超标     |
| 排序后扫描   | O(n log n) | O(1)       | 相邻比较，需修改或复制数组   |
| 异或一次遍历 | O(n)       | O(1)       | 单变量累积，满足题目双重要求 |

## 双语实现

  <TabItem label="Python" icon="seti:python">
    ```python
    # 只出现一次的数字 - Python 实现
    # 时间复杂度: O(n), 空间复杂度: O(1)
    # 核心思路: 全数组异或，成对元素抵消为 0
    def single_number(nums: list[int]) -> int:
        # result 初始化为 0，0 是异或单位元
        result = 0

        # 遍历一次，累积异或
        for num in nums:
            # ^= 为异或赋值，a ^ a = 0
            result ^= num

        # 循环结束即为只出现一次的元素
        return result

    # 测试用例
    print(single_number([2, 2, 1]))  # 1
    print(single_number([4, 1, 2, 1, 2]))  # 4
    print(single_number([1]))  # 1
    print(single_number([-1, -1, -2]))  # -2
    ```

## Python 与 TypeScript 差异点评

逻辑逐行对应，差异在类型系统与整数语义上：

<CodeCompare
  py={`# 遍历元素，无需声明类型
for num in nums:
    result ^= num`}
  ts={`// for...of 遍历元素，需 let 声明
for (const num of nums) {
  result ^= num;
}`}
/>

| 关注点   | Python                    | TypeScript                                 |
| -------- | ------------------------- | ------------------------------------------ |
| 遍历写法 | `for num in nums`         | `for (const num of nums)`，心智完全对应    |
| 变量声明 | `result = 0`，动态类型    | `let result = 0`，需区分 `let` 与 `const`  |
| 整数语义 | 无限精度，位运算不截断    | 位运算按 32 位有符号整数执行，超范围会截断 |
| 负数异或 | 数学意义上的无限位补码    | 32 位补码，结果在 32 位内一致              |
| 类型注解 | `list[int]`，运行时不检查 | `number[]` + 返回值 `: number`，编译期检查 |
| 输出测试 | `print(...)`              | `console.log(...)`                         |

:::note
题目数值范围在 32 位内，两种语言结果一致。若输入超出 32 位，TypeScript 位运算会先做 `ToInt32` 转换，而 Python 保持精确，此时不可直接迁移该解法。
:::

## 常见错误分析

### 1. 用哈希表交差，空间不达标

```python
# 能过但不符合要求：空间 O(n)
count = {}
for num in nums:
    count[num] = count.get(num, 0) + 1
```

题目明确要求 O(1) 空间。**改法**：看到"两次抵消、一次保留"优先想到异或，而非计数。

### 2. 初始化与循环范围配合错误

```python
# 错误：从 nums[0] 开始却遍历全数组，首元素被异或两次
result = nums[0]
for num in nums:
    result ^= num
```

`nums[0] ^ nums[0] = 0` 会把首元素消掉。**改法**：要么 `result = 0` 遍历全部，要么 `result = nums[0]` 从下标 1 开始，前后保持一致。

### 3. TypeScript 里误用 `Map.get` 计数且忘记判空

```typescript
// 错误：strict 下 get 可能返回 undefined
count.set(num, count.get(num) + 1);
```

`Map.get` 返回 `number | undefined`，直接相加得到 `NaN` 或编译报错。**改法**：使用 `(count.get(num) ?? 0) + 1`。正解的异或版本完全避开 `Map`，也就避开了这类 strict 坑。

## 面试变体

1. **其余出现三次，找出现一次的数**：异或不再适用，改为统计 32 个位上 1 的次数，次数不是 3 倍数的位即答案位。时间 O(32n) 即 O(n)、空间 O(1)。位统计算法在[计数比特](../counting-bits/)中有同类思想，可对照练习。
2. **有两个数只出现一次**：先全数组异或得到 `xor = a ^ b`，取最低位的 1 将数组分成两组，每组退化为本题，时间 O(n)、空间 O(1)。
3. **用集合对消**：遍历中见过则删除、没见过则加入，最后集合剩一个元素。时间 O(n)、空间 O(n)，适合讲清思路但不满足进阶要求，常作为过渡解法。

## 面试追问

- 为什么异或顺序不影响结果？（交换律与结合律保证配对与位置无关，答案要点是把数组重排为 `a ^ a ^ b ^ b ^ x` 的形式。）
- `result` 为何初始化为 0 而不是第一个元素？（0 是单位元，代码更短且无需处理空数组分支。）
- Python 与 TypeScript 做大数异或有何差异？（Python 无限精度，TS 按 32 位截断，超范围输入行为不同。）
- 该解法能否推广到"出现三次"？（不能，`a ^ a ^ a = a` 无法抵消，需要按位计数。）
