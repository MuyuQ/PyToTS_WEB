## 问题描述

给定非负整数 `n`，对 `0 <= i <= n` 的每个 `i`，计算其二进制表示中 `1` 的个数，返回长度为 `n + 1` 的数组 `ans`，其中 `ans[i]` 即 `i` 的答案。

**示例 1**

```text
输入：n = 2
输出：[0, 1, 1]
解释：0 -> 0（0 个 1），1 -> 1（1 个 1），2 -> 10（1 个 1）
```

**示例 2**

```text
输入：n = 5
输出：[0, 1, 1, 2, 1, 2]
解释：3 -> 11（2 个 1），4 -> 100（1 个 1），5 -> 101（2 个 1）
```

**约束条件**

- `0 <= n <= 10⁵`

**边界情况**：`n = 0` 时返回 `[0]`；结果数组长度必须为 `n + 1`；`dp[0] = 0` 为天然递推基，无需特殊分支；题目要求一次算出全部前缀答案，单个数调用库函数逐个计数不符合线性总时间要求。

## 暴力解与瓶颈

朴素做法是对每个 `i` 单独数位：转二进制字符串数 `1`，或循环 `while i: count += i & 1; i >>= 1`：

```python
def count_bits_brute(n: int) -> list[int]:
    ans = []
    for i in range(n + 1):
        ans.append(bin(i).count("1"))
    return ans
```

单个数的计数为 O(log i)，总时间为 O(n log n)；且每个答案独立重算，未利用相邻数字的二进制关联。瓶颈在于重复扫描相似位模式。优化方向是递推复用：`i` 去掉最低位后即为已算过的 `i >> 1`，补上最低位是否为 1 即可 O(1) 得出。

## 思路分析

最低有效位递推：`dp[i] = dp[i >> 1] + (i & 1)`。`i >> 1` 去掉最低位，结果下标小于 `i`，保证已计算；`i & 1` 取最低位，贡献 0 或 1。按 `i` 递增填表即得全部答案。

以 `n = 5` 为例：

| `i` | 二进制 | `i >> 1` | `dp[i >> 1]` | `i & 1` | `dp[i]` |
| --- | ------ | -------- | ------------ | ------- | ------- |
| 0   | 0      | —        | —            | —       | 0       |
| 1   | 1      | 0        | 0            | 1       | 1       |
| 2   | 10     | 1        | 1            | 0       | 1       |
| 3   | 11     | 1        | 1            | 1       | 2       |
| 4   | 100    | 2        | 1            | 0       | 1       |
| 5   | 101    | 2        | 1            | 1       | 2       |

等价变体为 Brian Kernighan 递推 `dp[i] = dp[i & (i - 1)] + 1`：`i & (i - 1)` 去掉最低位的 1，剩余部分已算过，加 1 补回。两者均为线性，主解采用更直观的前者。

:::tip
关键细节是填表顺序必须递增：`dp[i >> 1]` 与 `dp[i & (i - 1)]` 的下标都严格小于 `i`，只有从小到大才能保证引用已就绪；初始化 `[0] * (n + 1)` 后从 1 开始循环，`dp[0]` 保持为基。
:::

## 复杂度分析

| 解法           | 时间复杂度 | 空间复杂度 | 说明                     |
| -------------- | ---------- | ---------- | ------------------------ |
| 逐个数位       | O(n log n) | O(n)       | 每个数扫描全部二进制位   |
| 最低位递推     | O(n)       | O(n)       | 每数 O(1) 转移，单遍填表 |
| Kernighan 递推 | O(n)       | O(n)       | 同样线性，常数略有差异   |

结果数组本身占 O(n)，为输出必需空间；除此之外递推仅用常数变量，时间为最优线性。

## 双语实现

<Tabs syncKey="language">
  <TabItem label="Python" icon="seti:python">
    ```python
    # 比特位计数 - Python 实现（最低有效位递推）
    # 时间复杂度: O(n), 空间复杂度: O(n)
    # 核心思路: dp[i] = dp[i >> 1] + (i & 1)
    def count_bits(n: int) -> list[int]:
        # dp[i] 表示 i 的二进制中 1 的个数
        # dp[0] = 0 天然成立，为递推基
        dp = [0] * (n + 1)

        # 从 1 递增到 n，保证 dp[i >> 1] 已就绪
        for i in range(1, n + 1):
            # 去掉最低位后的答案，加上最低位贡献
            dp[i] = dp[i >> 1] + (i & 1)

        return dp

    # 测试用例
    print(count_bits(2))  # [0, 1, 1]
    print(count_bits(5))  # [0, 1, 1, 2, 1, 2]
    print(count_bits(0))  # [0]
    ```

    ```typescript
    // 比特位计数 - TypeScript 实现（最低有效位递推）
    // 时间复杂度: O(n), 空间复杂度: O(n)
    // 核心思路: dp[i] = dp[i >> 1] + (i & 1)
    function countBits(n: number): number[] {
      // dp[i] 表示 i 的二进制中 1 的个数
      // dp[0] = 0 天然成立，为递推基
      const dp: number[] = new Array(n + 1).fill(0);

      // 从 1 递增到 n，保证 dp[i >> 1] 已就绪
      for (let i = 1; i <= n; i++) {

        dp[i] = dp[i >> 1] + (i & 1);
      }

      return dp;
    }

    // 测试用例
    console.log(countBits(2)); // [0, 1, 1]
    console.log(countBits(5)); // [0, 1, 1, 2, 1, 2]
    console.log(countBits(0)); // [0]
    ```

位运算表达式完全同构，差异在数组初始化与类型声明上：

| 关注点     | Python                       | TypeScript                                        |
| ---------- | ---------------------------- | ------------------------------------------------- |
| 数组初始化 | `[0] * (n + 1)` 乘法复制     | `new Array(n + 1).fill(0)` 显式填充               |
| 循环形态   | `range(1, n + 1)` 右端含 `n` | `i <= n` 条件显式含 `n`                           |
| 位运算     | `>>`、`&` 语义一致           | `>>`、`&` 语义一致，可直接对照                    |
| 结果类型   | `list[int]`                  | `number[]`，`const` 绑定但内容可变                |
| 空洞风险   | 乘法初始化无空洞             | 若漏掉 `.fill(0)` 则为稀疏数组，`dp[i >> 1]` 为空 |
| 输出测试   | `print(...)`                 | `console.log(...)`                                |

:::note
TypeScript 的 `const dp` 限定的是绑定不可重新赋值，数组内容依然可写；`new Array(n + 1)` 若不 `fill`，元素为 `empty` 而非 0，参与加法得 `NaN`。Python 乘法初始化一步到位，无对应陷阱。
:::

## 常见错误分析

### 1. 循环从 0 开始且转移引用自身，逻辑错乱

```python
# 错误：i = 0 时 dp[0 >> 1] 即 dp[0] 自引
for i in range(0, n + 1):
    dp[i] = dp[i >> 1] + (i & 1)
```

`i = 0` 时右端读到正在写入的 `dp[0]`，虽数值恰好仍对，但破坏"引用已就绪"的不变量，改用 Kernighan 式 `dp[i & (i - 1)]` 时 `i = 0` 会出现 `dp[-1]` 越界语义。**改法**：固定从 1 开始，`dp[0]` 保持基值不动。

### 2. 对每个数单独数位，总时间退化

```python
# 错误：满足功能但复杂度为 O(n log n)
ans = [bin(i).count("1") for i in range(n + 1)]
```

小 `n` 可通过，大 `n` 或追问"能否线性"时失分。**改法**：识别"前缀全部答案"即递推信号，优先写 `dp[i >> 1]` 转移。

### 3. TypeScript 里漏掉 `fill(0)` 或误用无符号移位

```typescript
// 错误：稀疏数组参与运算得 NaN
const dp: number[] = new Array(n + 1);
dp[i] = dp[i >> 1] + (i & 1); // dp[i >> 1] 为 undefined
```

`strict` 下 `dp[i >> 1]` 类型为 `number`，编译器不拦截 `undefined` 的运行时值，加法结果为 `NaN` 并向后污染。**改法**：固定模板 `new Array(n + 1).fill(0)`；本题 `i` 非负，用 `>>` 即可，无需 `>>>`，混用反而增加心智负担。

## 面试变体

1. **单个数 1 的个数**：给定单个 `x` 求其汉明重量。Brian Kernighan 循环 `while x: x &= x - 1; count += 1`，时间为 O(k)（`k` 为 1 的个数），空间 O(1)。
2. **汉明距离**：求两数二进制不同位的个数。先 `xor = a ^ b`，再对 `xor` 用上条方法计数，时间 O(k)、空间 O(1)。位运算综合可对照[只出现一次的数字](../single-number/)体会异或的计数与消元双重用法。
3. **判断 2 的幂**：`n > 0 && (n & (n - 1)) === 0`。2 的幂仅含一个 1，去掉后为零，时间 O(1)、空间 O(1)，注意 `n <= 0` 的前置排除。
4. **按 1 的个数排序**：对数组按二进制 1 的个数升序、值升序排列。预计算权重后自定义比较器，总复杂度由排序主导为 O(n log n)，计数部分仍保持线性。

## 面试追问

- 为什么 `dp[i >> 1]` 一定已经算出？（`i >> 1` 等价于地板除以 2，`i >= 1` 时严格小于 `i`，递增填表保证引用已就绪。）
- `i & 1` 与 `i % 2` 有何区别？（非负数下等价；位运算意图更直接且通常更快；负数下两者语义分岔，本题 `i` 非负无需顾虑。）
- Kernighan 式与最低位式如何取舍？（前者语义是"去掉一个 1"，后者是"去掉最低位"；前者可自然扩展到单个数计数，后者表格形态更直观，渐进复杂度相同。）
- 空间能否压到 O(1)？（不能，结果数组本身占 O(n) 且为题目要求的输出；若只求单个 `n` 的答案则可 O(1)。）
