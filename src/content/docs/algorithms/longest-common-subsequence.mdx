## 问题描述

给定两个字符串 `text1` 和 `text2`，返回这两个字符串的最长公共子序列的长度。如果不存在公共子序列，返回 `0`。子序列指删除零或多个字符后保持相对顺序的新字符串，不要求连续。

**示例 1**

```text
输入：text1 = "abcde", text2 = "ace"
输出：3
解释：最长公共子序列是 "ace"，长度为 3。
```

**示例 2**

```text
输入：text1 = "abc", text2 = "def"
输出：0
解释：两串没有公共字符，不存在公共子序列。
```

**约束条件**

- `1 <= text1.length, text2.length <= 1000`
- `text1` 和 `text2` 仅由小写英文字母组成
- 只求长度时可用滚动数组优化，求具体子序列时需要保留完整 DP 表
- 结果长度不超过 `min(m, n)`

**边界情况**：任一串为空直接返回 `0`；两串完全相同时答案为串长；两串无公共字符时答案为 `0`，回溯构造返回空串。

## 暴力解与瓶颈

朴素解法是枚举 `text1` 的全部子序列并检查是否为 `text2` 的子序列：

```python
def lcs_brute(text1: str, text2: str) -> int:
    best = 0
    m = len(text1)
    for mask in range(1 << m):
        sub = "".join(text1[i] for i in range(m) if mask >> i & 1)
        it = iter(text2)
        if all(c in it for c in sub):
            best = max(best, len(sub))
    return best
```

`text1` 有 `2^m` 个子序列，每个检查 O(n)，总时间 O(2^m \* n)，m 稍大即不可用。瓶颈在于重复比较相同后缀，优化方向是记忆化前后缀的答案，用 DP 把指数级搜索压缩为网格填表。

## 思路分析

最优解是二维 DP：`dp[i][j]` 表示 `text1[0..i-1]` 与 `text2[0..j-1]` 的 LCS 长度。首行首列为 0，转移只看当前末字符是否相等：

- 相等：`dp[i][j] = dp[i-1][j-1] + 1`
- 不等：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

以 `text1 = "abcde"`、`text2 = "ace"` 为例，右下角附近的填表过程如下：

| `i/j`     | `""` | `a` | `c` | `e` |
| --------- | ---- | --- | --- | --- |
| `""`      | 0    | 0   | 0   | 0   |
| `"abc"`   | 0    | 1   | 2   | 2   |
| `"abcd"`  | 0    | 1   | 2   | 2   |
| `"abcde"` | 0    | 1   | 2   | 3   |

`dp[5][3] = 3` 即答案。只求长度时可压缩为两行滚动数组，求具体子序列时从右下角按来源回溯。

:::tip
关键细节是 DP 表多出一行一列表示空串，比较的是 `text1[i-1]` 与 `text2[j-1]`。下标错一位是最高频越界来源，写转移时先固定该对应关系。
:::

## 复杂度分析

| 解法             | 时间复杂度  | 空间复杂度   | 说明                           |
| ---------------- | ----------- | ------------ | ------------------------------ |
| 枚举子序列暴力解 | O(2^m \* n) | O(m)         | 指数级，不可接受               |
| 二维 DP 最优解   | O(m \* n)   | O(m \* n)    | 填表一次，可回溯构造具体子序列 |
| 滚动数组优化     | O(m \* n)   | O(min(m, n)) | 只求长度时保留两行即可         |

## 双语实现

<Tabs syncKey="language">
  <TabItem label="Python" icon="seti:python">
    ```python
    # 最长公共子序列 - Python 实现（二维 DP）
    # 时间复杂度: O(m * n), 空间复杂度: O(m * n)
    # 核心思路: dp[i][j] 存两前缀的 LCS 长度，末字符分合转移
    def longest_common_subsequence(text1: str, text2: str) -> int:
        # 两串长度
        m, n = len(text1), len(text2)
        # 多一行一列表示空串，初值 0
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # 注意下标减一对应 DP 表
                if text1[i - 1] == text2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        return dp[m][n]

    # 测试用例
    print(longest_common_subsequence("abcde", "ace"))  # 3
    print(longest_common_subsequence("abc", "abc"))  # 3
    print(longest_common_subsequence("abc", "def"))  # 0
    ```

    ```typescript
    // 最长公共子序列 - TypeScript 实现（二维 DP）
    // 时间复杂度: O(m * n), 空间复杂度: O(m * n)
    // 核心思路: dp[i][j] 存两前缀的 LCS 长度，末字符分合转移
    function longestCommonSubsequence(text1: string, text2: string): number {
      // 两串长度
      const m = text1.length;
      const n = text2.length;
      // 多一行一列表示空串，初值 0
      const dp: number[][] = Array.from({ length: m + 1 }, () =>
        new Array(n + 1).fill(0)
      );
      for (let i = 1; i <= m; i++) {
        for (let j = 1; j <= n; j++) {
          // 注意下标减一对应 DP 表
          if (text1[i - 1] === text2[j - 1]) {
            dp[i][j] = dp[i - 1][j - 1] + 1;
          } else {
            dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
          }
        }
      }
      return dp[m][n];
    }

    console.log(longestCommonSubsequence("abcde", "ace")); // 3
    console.log(longestCommonSubsequence("abc", "abc")); // 3
    console.log(longestCommonSubsequence("abc", "def")); // 0
    ```

## Python 与 TypeScript 差异点评

转移方程完全一致，差异在二维数组的创建与比较符号上：

```python
# 建表：列表推导生成 (m+1) x (n+1) 零矩阵
dp = [[0] * (n + 1) for _ in range(m + 1)]
if text1[i - 1] == text2[j - 1]:
    dp[i][j] = dp[i - 1][j - 1] + 1
```

```typescript
// 建表：Array.from 生成 (m+1) x (n+1) 零矩阵
const dp: number[][] = Array.from({ length: m + 1 }, () => new Array(n + 1).fill(0));
if (text1[i - 1] === text2[j - 1]) {
  dp[i][j] = dp[i - 1][j - 1] + 1;
}
```

| 关注点   | Python                              | TypeScript                                                |
| -------- | ----------------------------------- | --------------------------------------------------------- |
| 建表     | `[[0] * (n+1) for _ in range(m+1)]` | `Array.from({length: m+1}, () => new Array(n+1).fill(0))` |
| 字符比较 | `==` 比较字符                       | `===` 严格比较字符                                        |
| 取大值   | `max(a, b)` 内置                    | `Math.max(a, b)`                                          |
| 长度     | `len(text1)`                        | `text1.length`                                            |
| 类型注解 | `-> int`，运行时不检查              | `: number`，编译期检查                                    |
| 输出测试 | `print(...)`                        | `console.log(...)`                                        |

:::note
Python 写 `[[0] * (n+1)] * (m+1)` 会让各行共享同一列表，填表时一改全改。必须用列表推导逐行新建；TypeScript 侧对应坑是 `new Array(m+1).fill(new Array(n+1).fill(0))` 同样共享行，必须用 `Array.from` 回调逐行创建。
:::

## 常见错误分析

### 1. 混淆子序列与子串

```python
# 错误：按连续子串转移
dp[i][j] = dp[i - 1][j - 1] + 1 if text1[i-1] == text2[j-1] else 0
```

子串要求连续，不等即清零；子序列允许跳字符，不等时应继承上或左的最大值。**改法**：不等分支写 `max(dp[i-1][j], dp[i][j-1])`。

### 2. 下标错一位导致越界

```python
# 错误：直接用 text1[i] 对应 dp[i][j]
if text1[i] == text2[j]:
```

DP 表比字符串各多一行一列，`dp[i][j]` 对应 `text1[i-1]` 与 `text2[j-1]`。**改法**：比较时固定减一，循环从 1 开始。

### 3. TypeScript 里共享行引用

```typescript
// 错误：各行指向同一数组，strict 下类型通过但逻辑全错
const dp: number[][] = new Array(m + 1).fill(new Array(n + 1).fill(0));
```

修改 `dp[i][j]` 会污染整列。**改法**：用 `Array.from` 回调逐行 `new Array(n+1).fill(0)`。Python 侧对应坑是乘法建表共享引用，同样需要推导式逐行新建。

## 面试变体

1. **最长公共子串**：要求连续，不等即清零并记录最大值。时间 O(m \* n)、空间可优化到 O(n)，注意与本题转移的差异。
2. **编辑距离**：允许增删改（详见[编辑距离](../edit-distance/)）。转移多一个替换分支，时间 O(m _ n)、空间 O(m _ n)。
3. **最长回文子序列**：等价于 LCS(s, reverse(s))，时间 O(n^2)、空间 O(n^2)，注意去重语义。
4. **硬币找零对照**：同为 DP 填表（详见[硬币找零](../coin-change/)）。本题是二维前缀 DP，那题是一维金额 DP，对比状态定义方式。
5. **最长递增子序列**：同样求最长但只需一维 DP（详见[最长递增子序列](../longest-increasing-subsequence/)）。时间 O(n log n) 可用 patience 优化，体会维度差异。

## 面试追问

- 为什么不等时取上与左的最大值？（表示跳过 `text1[i-1]` 或 `text2[j-1]` 其中之一，继承已有最优。）
- 如何构造出具体子序列而不只是长度？（保留完整 DP 表，从右下角按来源回溯，相等走左上，不等走大的一侧。）
- 滚动数组优化后还能回溯吗？（不能，只剩长度信息；需要具体串时必须保留完整表或分治重构。）
- 输入规模 1000 时内存是否可行？（完整表约百万整数，两语言均可接受；更长时换滚动数组或 Hirschberg 分治。）
