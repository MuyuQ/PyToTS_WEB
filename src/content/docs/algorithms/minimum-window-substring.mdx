## 问题描述

给定两个字符串 `s` 和 `t`，返回 `s` 中涵盖 `t` 所有字符的最小子串。若不存在符合条件的子串，返回空字符串 `""`。涵盖指窗口中每种字符的数量都不低于 `t` 中的需求，顺序不限。

**示例 1**

```text
输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"
解释："BANC" 包含 A、B、C 各至少一个，且是满足条件的最短窗口。
```

**示例 2**

```text
输入：s = "a", t = "aa"
输出：""
解释：s 只有一个 a，无法提供两个 a，不存在可行窗口。
```

**约束条件**

- `1 <= s.length, t.length <= 10^5`
- `s` 和 `t` 由英文字母组成，区分大小写
- 若存在多个同长度最小窗口，返回任意一个即可
- 时间要求线性，暴力枚举子串不可接受

**边界情况**：`len(s) < len(t)` 直接返回空串；`t` 含重复字符时需求按频次计算；全串恰好满足时答案为整个 `s`。

## 暴力解与瓶颈

朴素解法是枚举 `s` 的全部子串并检查频次：

```python
from collections import Counter

def min_window_brute(s: str, t: str) -> str:
    need = Counter(t)
    best = ""
    for i in range(len(s)):
        for j in range(i + 1, len(s) + 1):
            window = Counter(s[i:j])
            if all(window[c] >= need[c] for c in need):
                if best == "" or len(window) < len(best):
                    best = s[i:j]
    return best
```

子串数量 O(n^2)，每次检查 O(n)，总时间 O(n^3) 量级。瓶颈在于大量窗口被重复统计，优化方向是复用窗口信息：右指针只向前扩张，左指针在满足条件时收缩，每个字符至多进出一次。

## 思路分析

最优解是滑动窗口加频次表：`need` 记录每种字符还缺几个，`missing` 记录总共还缺几个字符。右指针扩张纳入字符，满足条件后移动左指针压缩，直到不满足再继续扩张。

以 `s = "ADOBECODEBANC"`、`t = "ABC"` 的关键阶段为例：

| 步骤 | 右指针 `char` | `missing` 变化 | 窗口动作 |
| ---- | ------------- | -------------- | -------- |
| 1 | 前 6 字符 `ADOBEC` | `3 -> 0` | 首次集齐，窗口 `[0, 5]` |
| 2 | 收缩左指针过 `A` | `0 -> 1` | 记录候选，窗口不再满足 |
| 3 | 右指针走到末尾 `BANC` | `1 -> 0` | 再次集齐，窗口 `[9, 12]` |
| 4 | 继续收缩至 `BANC` 最小 | 保持 `0` | 更新答案为 `BANC` |

`need` 中正数表示还缺，零表示刚好，负数表示冗余，收缩时只看移出字符是否从满足变为不满足。

:::tip
关键细节是扩张与收缩共用同一套计数：`need[char] -= 1` 后若原值大于 0 则 `missing` 减一；收缩时 `need[s[left]] += 1` 后若新值大于 0 则 `missing` 加一。两处大于 0 的判断缺一不可。
:::

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 枚举子串暴力解 | O(n^3) | O(n) | 子串数量与频次检查双重爆炸 |
| 滑动窗口最优解 | O(m + n) | O(m)，m 为字符集 | 左右指针各走一遍，哈希表存频次 |

## 双语实现

  <TabItem label="Python" icon="seti:python">
    ```python
    # 最小覆盖子串 - Python 实现（滑动窗口）
    # 时间复杂度: O(m + n), 空间复杂度: O(m)
    # 核心思路: need 存还缺频次，missing 存总缺数，满足即收缩
    from collections import Counter

    def min_window(s: str, t: str) -> str:
        # t 中每种字符的需求频次
        need = Counter(t)
        # 还缺的总字符数
        missing = len(t)
        left = 0
        min_len = float("inf")
        min_start = 0
        for right, char in enumerate(s):
            # 该字符仍被需要则总缺数减一
            if need[char] > 0:
                missing -= 1
            need[char] -= 1
            # 集齐后收缩左边界
            while missing == 0:
                if right - left + 1 < min_len:
                    min_len = right - left + 1
                    min_start = left
                need[s[left]] += 1
                if need[s[left]] > 0:
                    missing += 1
                left += 1
        return "" if min_len == float("inf") else s[min_start:min_start + min_len]

    # 测试用例
    print(min_window("ADOBECODEBANC", "ABC"))  # BANC
    print(min_window("a", "a"))  # a
    print(min_window("a", "aa"))  # 空串
    ```

    ```typescript
    // 最小覆盖子串 - TypeScript 实现（滑动窗口）
    // 时间复杂度: O(m + n), 空间复杂度: O(m)
    // 核心思路: need 存还缺频次，missing 存总缺数，满足即收缩
    function minWindow(s: string, t: string): string {
      // t 中每种字符的需求频次
      const need = new Map<string, number>();
      for (const char of t) {
        need.set(char, (need.get(char) ?? 0) + 1);
      }
      // 还缺的总字符数
      let missing = t.length;
      let left = 0;
      let minLen = Infinity;
      let minStart = 0;
      for (let right = 0; right < s.length; right++) {
        const char = s[right];
        const count = need.get(char) ?? 0;
        // 该字符仍被需要则总缺数减一
        if (count > 0) {
          missing--;
        }
        need.set(char, count - 1);
        // 集齐后收缩左边界
        while (missing === 0) {
          if (right - left + 1 < minLen) {
            minLen = right - left + 1;
            minStart = left;
          }
          const leftChar = s[left];
          const leftCount = need.get(leftChar) ?? 0;
          need.set(leftChar, leftCount + 1);
          if (leftCount + 1 > 0) {
            missing++;
          }
          left++;
        }
      }
      return minLen === Infinity ? "" : s.substring(minStart, minStart + minLen);
    }

    // 测试用例
    console.log(minWindow("ADOBECODEBANC", "ABC")); // BANC
    console.log(minWindow("a", "a")); // a
    console.log(minWindow("a", "aa")); // 空串
    ```

## Python 与 TypeScript 差异点评

窗口主循环逐行对应，差异在频次容器的缺席语义上：

<CodeCompare
  py={`# Counter 缺席键读到 0，可直接比较
if need[char] > 0:
    missing -= 1
need[char] -= 1`}
  ts={`// Map 缺席返回 undefined，需兜底为 0
const count = need.get(char) ?? 0;
if (count > 0) {
  missing--;
}
need.set(char, count - 1);`}
/>

| 关注点 | Python | TypeScript |
| ------ | ------ | ---------- |
| 频次容器 | `Counter(t)` 一行建表 | `Map` 循环累加建表 |
| 缺席读取 | `need[char]` 缺席返回 `0` | `need.get(char)` 缺席返回 `undefined`，用 `?? 0` 兜底 |
| 收缩取值 | `need[s[left]]` 直接读写 | `need.get(leftChar) ?? 0` 先读后写 |
| 无穷大 | `float("inf")` | `Infinity` |
| 切片 | `s[min_start:min_start+min_len]` | `s.substring(minStart, minStart+minLen)` |
| 命名风格 | `min_window`、`min_len` 蛇形 | `minWindow`、`minLen` 驼峰 |

:::note
TypeScript 的 `need.get(leftChar)!` 非空断言在收缩阶段看似成立，但窗口滑过从未见过的字符时仍可能读到 `undefined`。正解用 `?? 0` 兜底后再加一，比 `!` 更稳；Python 侧 `Counter` 无此问题，但换成普通 `dict` 就必须用 `get(char, 0)`。
:::

## 常见错误分析

### 1. 收缩条件写成频次全满足扫描

```python
# 错误：每次收缩都扫描整个 need，退化为 O(n * 字符集)
while all(v <= 0 for v in need.values()):
```

虽然正确但每次 O(字符集)。**改法**：维护 `missing` 计数器，扩张收缩只做 O(1) 更新。

### 2. 忘记处理无解分支

```python
# 错误：min_len 初值 0，无解时返回 s[0:0] 语义混乱
min_len = 0
```

无解与解为空串无法区分。**改法**：初值设无穷，结束时判断仍为无穷则返回 `""`。

### 3. TypeScript 里误用 `||` 代替 `??`

```typescript
// 错误：频次 0 被误判为缺席
need.set(char, (need.get(char) || 0) + 1);
```

本题频次非负，`0 || 0` 仍为 `0` 看似无害，但在含 `0` 与 `NaN` 的通用计数里语义错误。**改法**：统一用 `?? 0` 只兜底 `null` 与 `undefined`。Python 对应坑是普通字典缺 `get(char, 0)` 兜底导致 `KeyError`。

## 面试变体

1. **无重复最长子串**：窗口约束换成字符不重复（详见[无重复字符的最长子串](../longest-substring-without-repeating/)）。同样双指针，时间 O(n)、空间 O(字符集)。
2. **含排列子串**：判断 `s` 是否含 `t` 的某个排列，窗口固定为 `len(t)`，频次全满足即命中。时间 O(n)、空间 O(m)。
3. **至多 K 个不同字符**：窗口内不同字符数不超过 K，收缩条件换成集合大小，时间 O(n)、空间 O(k)。
4. **最小窗口升级版**：`t` 含重复字符时需求按频次而非集合，`missing` 初值为 `len(t)` 而非种类数，复杂度不变。
5. **全集对照**：窗口题都可用左右指针模板串联复习，体会扩张与收缩的不变量设计。

## 面试追问

- 为什么左右指针各只走一遍？（右指针单调扩张，左指针满足即收缩且永不回退，每个字符至多进出一次。）
- `need` 为负表示什么？（窗口中该字符冗余，收缩时优先丢弃冗余字符不影响满足性。）
- `len(s) < len(t)` 为什么可直接返回？（字符总数不足，不可能满足频次，连窗口都不必展开。）
- 如何证明记录的最小窗口一定最优？（每次收缩都试探了当前右端下的最左可行位置，所有右端的最优都被枚举过。）
