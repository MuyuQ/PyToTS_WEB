## 问题描述

给你两个单词 `word1` 和 `word2`，返回将 `word1` 转换成 `word2` 所使用的最少操作数。可以对单词进行插入一个字符、删除一个字符、替换一个字符三种操作。

**示例 1**

```text
输入：word1 = "horse", word2 = "ros"
输出：3
解释：horse -> rorse（替换 h 为 r）-> rose（删除 r）-> ros（删除 e）。
```

**示例 2**

```text
输入：word1 = "intention", word2 = "execution"
输出：5
解释：5 次操作是已知的最优解之一。
```

**约束条件**

- `0 <= word1.length, word2.length <= 500`
- `word1` 和 `word2` 由小写英文字母组成

**边界情况**：任一单词为空时答案是另一单词的长度（全插入或全删除）；两串相等时答案为 0；`("", "")` 返回 0。一维 DP 的初始数组 `dp = [0..n]` 恰好就是"空串转前缀"的边界答案。

## 暴力解与瓶颈

朴素想法是纯递归：比较两串首字符，相同则同时前进一步，不同则尝试删、插、替三个分支取最小：

```python
def min_distance_brute(word1: str, word2: str) -> int:
    if not word1:
        return len(word2)
    if not word2:
        return len(word1)
    if word1[0] == word2[0]:
        return min_distance_brute(word1[1:], word2[1:])
    return 1 + min(
        min_distance_brute(word1[1:], word2),      # 删除 word1 首字符
        min_distance_brute(word1, word2[1:]),      # 插入 word2 首字符
        min_distance_brute(word1[1:], word2[1:]),  # 替换首字符
    )
```

三个分支大量重叠：`(i, j)` 状态会被不同路径反复求解，时间 O(3^(m+n))，且切片每次复制字符串。瓶颈在于**重叠子问题被重复计算**。优化方向是**记忆化填表**：`dp[i][j]` 存"前缀对前缀"的答案，每个状态只算一次，总时间 O(m·n)，再把二维表压缩到一维。

## 思路分析

定义 `dp[i][j]` 为 `word1[0..i-1]` 转成 `word2[0..j-1]` 的最少操作数。字符相同时无需操作，继承左上角；不同时取删、插、替三者最小加一：上方 `dp[i-1][j]` 加一对应删除 `word1[i-1]`，左方 `dp[i][j-1]` 加一对应插入 `word2[j-1]`，左上 `dp[i-1][j-1]` 加一对应替换。一维压缩后用 `prev` 保存左上角旧值，`temp` 暂存上方旧值，`dp[0] = i` 负责每行首列。

以 `word1 = "horse"`、`word2 = "ros"` 为例，一维数组的逐行快照：

| 行 | 含义 | `dp` 数组 |
| -- | ---- | --------- |
| `i=0` | 空串转 `""/"r"/"ro"/"ros"` | `[0, 1, 2, 3]` |
| `i=1`（`h`） | `"h"` 转各前缀 | `[1, 1, 2, 3]` |
| `i=2`（`o`） | `"ho"` 转各前缀（`o` 命中） | `[2, 2, 1, 2]` |

最终 `dp[3]` 沿剩余行继续收敛到 3。

:::tip
关键细节是**更新顺序三件套**：`temp` 先存上方旧值，`dp[j]` 按规则覆盖，`prev = temp` 留给下一列当左上角。三句顺序错一句，左上角就被污染，这是本题最难查的 bug。
:::

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| ---- | ---------- | ---------- | ---- |
| 纯递归三分支 | O(3^(m+n)) | O(m + n)，递归栈加切片复制 | 重叠子问题被反复求解 |
| 二维 DP | O(m·n) | O(m·n) | 每个状态恰好计算一次 |
| 一维 DP（正解） | O(m·n) | O(n) | 只保留上一行，`prev`/`temp` 补齐左上与上方 |

## 双语实现

<Tabs syncKey="language">
  <TabItem label="Python" icon="seti:python">
    ```python
    # 编辑距离 - Python 实现 (一维 DP)
    # 时间复杂度: O(m*n), 空间复杂度: O(n)
    # 核心思路: dp[j] 存前缀对前缀的答案，prev 补左上角
    def min_distance(word1: str, word2: str) -> int:
        # m, n: 两单词长度
        m, n = len(word1), len(word2)

        # 初始行：空串转 word2 前缀需要 j 次插入
        dp = list(range(n + 1))  # [0, 1, 2, ..., n]

        # 外层遍历 word1 前缀（行）
        for i in range(1, m + 1):
            # prev 存左上角 dp[i-1][0]，此时 dp[0] 尚未覆盖
            prev = dp[0]
            # 首列：word1 前缀转空串需要 i 次删除
            dp[0] = i

            # 内层遍历 word2 前缀（列），必须从左到右
            for j in range(1, n + 1):
                # temp 存上方 dp[i-1][j]，留给下一列当左上角
                temp = dp[j]

                if word1[i - 1] == word2[j - 1]:
                    # 字符相同：继承左上角，无需操作
                    dp[j] = prev
                else:
                    # 上方=删除，左方=插入，左上=替换
                    dp[j] = min(dp[j], dp[j - 1], prev) + 1

                # 向右推进：当前上方成为下一列的左上
                prev = temp

        # 右下角即两完整单词的答案
        return dp[n]

    # 测试用例
    print(min_distance("horse", "ros"))  # 3
    print(min_distance("intention", "execution"))  # 5
    print(min_distance("", ""))  # 0
    print(min_distance("a", ""))  # 1
    ```

    ```typescript
    // 编辑距离 - TypeScript 实现 (一维 DP)
    // 时间复杂度: O(m*n), 空间复杂度: O(n)
    // 核心思路: dp[j] 存前缀对前缀的答案，prev 补左上角
    function minDistance(word1: string, word2: string): number {
      // m, n: 两单词长度
      const m = word1.length;
      const n = word2.length;

      // 初始行：空串转 word2 前缀需要 j 次插入
      const dp: number[] = Array.from({ length: n + 1 }, (_, i) => i);

      // 外层遍历 word1 前缀（行）
      for (let i = 1; i <= m; i++) {
        // prev 存左上角 dp[i-1][0]，此时 dp[0] 尚未覆盖
        let prev = dp[0];
        // 首列：word1 前缀转空串需要 i 次删除
        dp[0] = i;

        // 内层遍历 word2 前缀（列），必须从左到右
        for (let j = 1; j <= n; j++) {
          // temp 存上方 dp[i-1][j]，留给下一列当左上角
          const temp = dp[j];

          if (word1[i - 1] === word2[j - 1]) {
            // 字符相同：继承左上角，无需操作
            dp[j] = prev;
          } else {
            // 上方=删除，左方=插入，左上=替换
            dp[j] = Math.min(dp[j], dp[j - 1], prev) + 1;
          }

          // 向右推进：当前上方成为下一列的左上
          prev = temp;
        }
      }

      // 右下角即两完整单词的答案
      return dp[n];
    }

    // 测试用例
    console.log(minDistance("horse", "ros")); // 3
    console.log(minDistance("intention", "execution")); // 5
    console.log(minDistance("", "")); // 0
    console.log(minDistance("a", "")); // 1
    ```

## Python 与 TypeScript 差异点评

一维 DP 的写法几乎逐行可译：

<CodeCompare
  py={`# 初始行：range 直接生成 0..n
dp = list(range(n + 1))`}
  ts={`// 初始行：Array.from 映射生成 0..n
const dp: number[] = Array.from({ length: n + 1 }, (_, i) => i);`}
/>

| 关注点 | Python | TypeScript |
| ------ | ------ | ---------- |
| 数组初始化 | `list(range(n + 1))` | `Array.from({ length: n + 1 }, (_, i) => i)` |
| 三值取小 | `min(a, b, c)` 内建支持多参数 | `Math.min(a, b, c)` 同样支持多参数 |
| 循环变量 | `for i in range(1, m + 1)` | `for (let i = 1; i <= m; i++)`，`let` 因递增 |
| 不变量 | `temp`/`prev` 普通赋值 | `const temp`（单轮不变）、`let prev`（跨轮更新） |
| 字符比较 | `==` | `===` |
| 输出测试 | `print(...)` | `console.log(...)` |

:::note
`dp` 用 `const` 声明但内容可变：`const` 锁的是绑定不是内容，`dp[j] = ...` 与 `dp[0] = i` 都合法。如果误用 `let` 重赋整个数组，反而会丢掉引用语义——可变数组配 `const` 是正解姿势。
:::

## 常见错误分析

### 1. `prev`/`temp` 更新顺序错乱

```python
# 错误：先覆盖 dp[j] 再取 temp，上方旧值永久丢失
if word1[i - 1] == word2[j - 1]:
    dp[j] = prev
else:
    dp[j] = min(dp[j], dp[j - 1], prev) + 1
temp = dp[j]  # 此时 dp[j] 已是新值，temp 存错了
prev = temp
```

`temp` 必须在覆盖之前保存 `dp[j]`（即上方旧值）。顺序一错，`prev` 传给下一列的是新值而非左上角，`"horse"`/`"ros"` 会算出 4 而不是 3。**改法**：默念口诀"存、算、传"——存上方、算当前、传左上。

### 2. 忘记每行重置 `dp[0] = i`

首列表示"转空串"，答案恒为行号 `i`。漏掉这一行，首列残留上一轮的值，整行连锁算错。`("", "abc")` 这类单边为空的输入最先暴露该问题：外层循环零次，全靠初始行 `[0, 1, 2, 3]` 作答。

### 3. TypeScript 里参数漏写类型

```typescript
// 错误：strict 下隐式 any 参数直接编译失败
function minDistance(word1, word2) {
  // 'word1' 隐式具有 'any' 类型
}
```

`strict` 包含 `noImplicitAny`，函数参数必须显式标注。这是 JS 迁移 TS 的第一道坎：正解签名 `(word1: string, word2: string): number` 把输入输出一次写清。Python 的注解运行时不检查，TS 的注解编译期强制执行。

## 面试变体

1. **删除距离（只能删除）**：操作只剩删除，最优解退化为 `m + n - 2 * LCS`，其中 LCS 是最长公共子序列（详见[最长公共子序列](../longest-common-subsequence/)）。复杂度仍为 O(m·n)，但状态转移只剩"相等继承、否则取上左最大"。
2. **一次编辑判断**：判断两串是否可通过至多一次编辑互转。无需 DP，双指针一次扫描定位首个差异，再看剩余后缀能否对齐，时间 O(n)、空间 O(1)。追问点：插入、删除、替换三种情况如何统一？
3. **单词拆分**：同为字符串 DP，但状态是一维"前缀可分性"（详见[单词拆分](../word-break/)）。对比两题能讲清 DP 维度由什么决定：编辑距离比较两个串所以二维，单词拆分只看一个串所以一维。

## 面试追问

- 覆盖前的 `dp[j]` 为什么恰好是"上方"？（一维数组保留的是上一行；内层从左到右推进，`dp[j]` 在被覆盖前还没轮到本行，所以仍是上一行同列，即上方。）
- `prev` 为什么恰好是"左上角"？（`prev` 存的是上一列覆盖前的上方，也就是上一行前一列；列指针右移一格后，它正好落在当前格的左上。）
- 两个输入串谁当行谁当列有讲究吗？（时间无差别；空间 O(n) 取决于列长度，把更短的串放列可压到 O(min(m, n))。）
