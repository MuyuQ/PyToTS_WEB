## 问题描述

给定一个区间集合 `intervals`，其中 `intervals[i] = [start_i, end_i]`，合并所有重叠的区间，并返回一个不重叠的区间数组。

**示例 1**

```text
输入：intervals = [[1, 3], [2, 6], [8, 10], [15, 18]]
输出：[[1, 6], [8, 10], [15, 18]]
解释：[1, 3] 与 [2, 6] 重叠合并为 [1, 6]，其余不重叠。
```

**示例 2**

```text
输入：intervals = [[1, 4], [4, 5]]
输出：[[1, 5]]
解释：端点相接也算重叠，合并为 [1, 5]。
```

**约束条件**

- `1 <= intervals.length <= 10⁴`
- `intervals[i].length == 2`
- `0 <= start_i <= end_i <= 10⁴`

**边界情况**：单区间直接返回；完全包含（如 `[1, 10]` 含 `[2, 3]`）合并时结束取最大值；端点相等是否合并取决于题意，本题按重叠处理；空数组虽不在约束内，代码保留兜底分支更稳健。

## 暴力解与瓶颈

朴素想法是两两比较：反复扫描区间对，发现重叠就合并，直到一轮无变化为止：

```python
def merge_brute(intervals: list[list[int]]) -> list[list[int]]:
    merged = [list(x) for x in intervals]
    changed = True
    while changed:
        changed = False
        for i in range(len(merged)):
            for j in range(i + 1, len(merged)):
                if merged[i][0] <= merged[j][1] and merged[j][0] <= merged[i][1]:
                    merged[i] = [min(merged[i][0], merged[j][0]), max(merged[i][1], merged[j][1])]
                    merged.pop(j)
                    changed = True
                    break
            if changed:
                break
    return merged
```

每合并一次就重扫，时间 O(n³) 量级，且删除元素导致索引抖动。瓶颈在于**重叠区间在无序时散落各处**，只能反复比对。优化方向是先按起点排序：排序后重叠区间必相邻，一次线性扫描即可合并。

## 思路分析

最优解分两步：按起点升序排序；维护 `merged`，新区间与最后一个比较，起点小于等于末尾即重叠，更新末尾为两者结束的最大值，否则直接追加。

以 `[[1, 3], [2, 6], [8, 10], [15, 18]]` 为例（已排序）：

| 步骤 | `current` | `merged` 末尾 | 判断              | `merged`                     |
| ---- | --------- | ------------- | ----------------- | ---------------------------- |
| 初始 | —         | —             | 存入首区间        | `[[1, 3]]`                   |
| 1    | `[2, 6]`  | `[1, 3]`      | `2 <= 3` 重叠     | `[[1, 6]]`                   |
| 2    | `[8, 10]` | `[1, 6]`      | `8 > 6` 不重叠    | `[[1, 6], [8, 10]]`          |
| 3    | `[15, 18]`| `[8, 10]`     | `15 > 10` 不重叠  | `[[1, 6], [8, 10], [15, 18]]` |

:::tip
关键细节有两处：判断用 `current[0] <= last[1]`，等号对应端点相接；合并用 `max(last[1], current[1])`，防止大区间吞掉小区间后结束反而变小。
:::

## 复杂度分析

| 解法       | 时间复杂度 | 空间复杂度 | 说明                           |
| ---------- | ---------- | ---------- | ------------------------------ |
| 两两反复合并 | O(n²) ~ O(n³) | O(n)    | 需多轮扫描，删除元素开销大     |
| 排序一次扫描 | O(n log n) | O(n)      | 排序主导，扫描 O(n)，结果 O(n) |

## 双语实现

<Tabs syncKey="language">
  <TabItem label="Python" icon="seti:python">
    ```python
    # 合并区间 - Python 实现（排序 + 一次扫描）
    # 时间复杂度: O(n log n), 空间复杂度: O(n)
    # 核心思路: 排序后重叠区间相邻，比较末尾即可
    def merge_intervals(intervals: list[list[int]]) -> list[list[int]]:
        # 空数组兜底，约束外输入也不崩溃
        if not intervals:
            return []

        # 按起点升序排序，重叠区间变为相邻
        intervals.sort(key=lambda x: x[0])

        # 首区间先入结果，后续逐个合并
        merged = [intervals[0]]

        for current in intervals[1:]:
            last = merged[-1]
            # 起点 <= 末尾即重叠（含端点相接）
            if current[0] <= last[1]:
                # 结束取最大值，处理完全包含
                last[1] = max(last[1], current[1])
            else:
                merged.append(current)

        return merged

    # 测试用例
    print(merge_intervals([[1, 3], [2, 6], [8, 10], [15, 18]]))
    # [[1, 6], [8, 10], [15, 18]]
    print(merge_intervals([[1, 4], [4, 5]]))  # [[1, 5]]
    print(merge_intervals([[1, 4], [2, 3]]))  # [[1, 4]]
    ```

    ```typescript
    // 合并区间 - TypeScript 实现（排序 + 一次扫描）
    // 时间复杂度: O(n log n), 空间复杂度: O(n)
    // 核心思路: 排序后重叠区间相邻，比较末尾即可
    function mergeIntervals(intervals: number[][]): number[][] {
      // 空数组兜底，约束外输入也不崩溃
      if (intervals.length === 0) {
        return [];
      }

      // 按起点升序排序，重叠区间变为相邻
      intervals.sort((a, b) => a[0] - b[0]);

      // 首区间先入结果，后续逐个合并
      const merged: number[][] = [intervals[0]];

      for (let i = 1; i < intervals.length; i++) {
        const current = intervals[i];
        const last = merged[merged.length - 1];
        // 起点 <= 末尾即重叠（含端点相接）
        if (current[0] <= last[1]) {
          // 结束取最大值，处理完全包含
          last[1] = Math.max(last[1], current[1]);
        } else {
          merged.push(current);
        }
      }

      return merged;
    }

    // 测试用例
    console.log(mergeIntervals([[1, 3], [2, 6], [8, 10], [15, 18]]));
    // [[1, 6], [8, 10], [15, 18]]
    console.log(mergeIntervals([[1, 4], [4, 5]])); // [[1, 5]]
    console.log(mergeIntervals([[1, 4], [2, 3]])); // [[1, 4]]
    ```

## Python 与 TypeScript 差异点评

合并逻辑逐行对应，最大差异在排序写法上：

<CodeCompare
  py={`# 按起点排序，key 明确
intervals.sort(key=lambda x: x[0])`}
  ts={`// 按起点排序，必须传比较函数
intervals.sort((a, b) => a[0] - b[0]);`}
/>

| 关注点   | Python                              | TypeScript                                     |
| -------- | ----------------------------------- | ---------------------------------------------- |
| 排序写法 | `sort(key=lambda x: x[0])`          | `sort((a, b) => a[0] - b[0])`，无比较函数按字典序 |
| 取末尾   | `merged[-1]` 负索引                 | `merged[merged.length - 1]`，需显式算下标      |
| 取最大值 | `max(last[1], current[1])`          | `Math.max(last[1], current[1])`                |
| 空数组判断 | `if not intervals`                | `if (intervals.length === 0)`                  |
| 变量声明 | `merged = [intervals[0]]`           | `const merged: number[][] = [intervals[0]]`    |
| 输出测试 | `print(...)`                        | `console.log(...)`                             |

:::note
JS 的 `sort()` 默认按字符串比较，`[10, 2]` 会排在 `[2, 3]` 之前，不传比较函数必错。Python 的 `sort` 默认按数值比较，`key` 只是显式意图。
:::

## 常见错误分析

### 1. 忘记先排序

```python
# 错误：直接扫描无序区间
merged = [intervals[0]]
for current in intervals[1:]:
    ...
```

无序时重叠区间不相邻，一次扫描会漏合。**改法**：扫描前先按起点排序，排序是整个算法成立的前提。

### 2. 合并时直接覆盖结束位置

```python
# 错误：[1, 10] 与 [2, 3] 合并后变成 [1, 3]
last[1] = current[1]
```

完全包含场景下结束反而缩小。**改法**：`last[1] = max(last[1], current[1])`，对应 TS 的 `Math.max`。

### 3. TypeScript 里忽略索引可空与原地副作用

```typescript
// 错误：strict 下 intervals[0] 可能是 undefined
const merged: number[][] = [intervals[0]];
```

判空后 `intervals[0]` 在宽松配置下可编译，严格配置（`noUncheckedIndexedAccess`）下仍报错。**改法**：判空后用 `intervals[0]!` 或取局部变量收窄。另一坑是 `sort` 原地修改输入，若调用方需保留原数组，应先 `[...intervals].sort(...)`。Python 的 `sort` 同样原地，语义一致。

## 面试变体

1. **插入区间**：新区间的起点决定插入位置，左右分别合并重叠部分。排序已部分成立时可 O(n) 插入，无需重排，空间 O(n)。
2. **会议室能否全参加**：排序后检查相邻是否重叠即可，本质是合并的判定版。时间 O(n log n)、空间 O(1)（不计排序栈）。
3. **区间交集**：双指针同步走两个已排序列表，重叠部分取 `max(起点)` 与 `min(终点)`。时间 O(m + n)、空间 O(m + n) 存结果。

## 面试追问

- 为什么排序后一次扫描就足够？（排序使重叠区间相邻，`merged` 末尾已是当前最大值前的前缀合并，答案要点是前缀不变量。）
- 端点相等算不算重叠？（取决于题意，本题 `<=` 合并；会议室问题同样用 `<=` 判冲突。）
- 合并时为何必须取 `max`？（处理完全包含，覆盖会丢失原末尾的更大值。）
- 原地排序有何副作用？（输入被改写，多测例复用同一数组会出错，需要时先拷贝。）
