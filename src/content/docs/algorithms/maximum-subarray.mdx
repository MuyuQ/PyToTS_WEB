## 问题描述

给定整数数组 `nums`，找出和最大的连续子数组（至少包含一个元素），返回其最大和。

**示例 1**

```text
输入：nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
输出：6
解释：子数组 [4, -1, 2, 1] 的和为 6，是最大值
```

**示例 2**

```text
输入：nums = [5, 4, -1, 7, 8]
输出：23
解释：整个数组的和为 23，是最大值
```

**约束条件**

- `1 <= nums.length <= 10⁵`
- `-10⁴ <= nums[i] <= 10⁴`

**边界情况**：全负数组时答案为最大单元素，不可初始化为 0；单元素数组直接返回该元素；空数组在 LeetCode 约束下不会出现，工程实现可约定返回 0 兜底；和可能超出小整数范围，累加变量需使用正常数值类型。

## 暴力解与瓶颈

朴素做法是枚举所有起点与终点并求和：

```python
def max_sub_array_brute(nums: list[int]) -> int:
    best = nums[0]
    for i in range(len(nums)):
        total = 0
        for j in range(i, len(nums)):
            total += nums[j]
            best = max(best, total)
    return best
```

起点终点组合为 O(n²)，每组求和若不复用则更高。瓶颈在于重复计算重叠区间的和。优化方向是增量决策：从左到右维护"以当前位置结尾的最大子数组和"，每个位置只需决定延续前段还是从当前重开，一遍即可。

## 思路分析

Kadane 算法的核心是局部与全局两个变量：`current_sum` 表示以当前位置结尾的最大和，`max_sum` 表示全局历史最优。转移为 `current_sum = max(num, current_sum + num)`：前段为负则延续不如重开，前段非负则延续更优；随后用 `current_sum` 更新 `max_sum`。

以 `nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]` 为例：

| 步骤 | `num` | `current_sum` 更新前 | 更新后 | `max_sum` |
| ---- | ----- | -------------------- | ------ | --------- |
| 初始 | —     | —                    | -2     | -2        |
| 1    | 1     | -2                   | 1      | 1         |
| 2    | -3    | 1                    | -2     | 1         |
| 3    | 4     | -2                   | 4      | 4         |
| 4    | -1    | 4                    | 3      | 4         |
| 5    | 2     | 3                    | 5      | 5         |
| 6    | 1     | 5                    | 6      | 6         |
| 7    | -5    | 6                    | 1      | 6         |
| 8    | 4     | 1                    | 5      | 6         |

:::tip
关键细节是初始化必须为 `nums[0]` 而非 0，否则全负数组会被错误回答为 0。循环从第二个元素开始，`current_sum` 与 `max_sum` 的更新顺序固定为先局部后全局。
:::

## 复杂度分析

| 解法        | 时间复杂度 | 空间复杂度 | 说明                         |
| ----------- | ---------- | ---------- | ---------------------------- |
| 枚举起终点  | O(n²)      | O(1)       | 组合爆炸，重叠区间反复求和   |
| 分治        | O(n log n) | O(log n)   | 跨中点情形需额外合并，栈开销 |
| Kadane 递推 | O(n)       | O(1)       | 单遍扫描，仅两个累加变量     |

Kadane 为最优：每个元素恰访问一次，时间为线性；仅用两个标量，空间为常数；且天然处理全负情形。

## 双语实现

<Tabs syncKey="language">
  <TabItem label="Python" icon="seti:python">
    ```python
    # 最大子数组和 - Python 实现（Kadane 算法）
    # 时间复杂度: O(n), 空间复杂度: O(1)
    # 核心思路: current = max(num, current + num)
    def max_sub_array(nums: list[int]) -> int:
        # 空数组兜底，约束内不会触发
        if not nums:
            return 0

        # 以首元素初始化，保证全负数组正确
        max_sum = current_sum = nums[0]

        # 从第二个元素开始决策延续或重开
        for num in nums[1:]:
            # 前段为负则重开，否则延续
            current_sum = max(num, current_sum + num)
            # 用局部最优更新全局最优
            max_sum = max(max_sum, current_sum)

        return max_sum

    # 测试用例
    print(max_sub_array([-2, 1, -3, 4, -1, 2, 1, -5, 4]))  # 6
    print(max_sub_array([1]))  # 1
    print(max_sub_array([5, 4, -1, 7, 8]))  # 23
    ```

    ```typescript
    // 最大子数组和 - TypeScript 实现（Kadane 算法）
    // 时间复杂度: O(n), 空间复杂度: O(1)
    // 核心思路: current = max(num, current + num)
    function maxSubArray(nums: number[]): number {
      // 空数组兜底，约束内不会触发
      if (nums.length === 0) {
        return 0;
      }

      // 以首元素初始化，保证全负数组正确
      let maxSum = nums[0];
      let currentSum = nums[0];

      // 从第二个元素开始决策延续或重开
      for (let i = 1; i < nums.length; i++) {
        const num = nums[i];
        // 前段为负则重开，否则延续
        currentSum = Math.max(num, currentSum + num);
        // 用局部最优更新全局最优
        maxSum = Math.max(maxSum, currentSum);
      }

      return maxSum;
    }

    // 测试用例
    console.log(maxSubArray([-2, 1, -3, 4, -1, 2, 1, -5, 4])); // 6
    console.log(maxSubArray([1])); // 1
    console.log(maxSubArray([5, 4, -1, 7, 8])); // 23
    ```

## Python 与 TypeScript 差异点评

转移方程逐行对应，差异在迭代形态与极值函数上：

<CodeCompare
  py={`# 切片迭代 + 内置 max
for num in nums[1:]:
    current_sum = max(num, current_sum + num)
    max_sum = max(max_sum, current_sum)`}
  ts={`// 索引迭代 + Math.max
for (let i = 1; i < nums.length; i++) {
  const num = nums[i];
  currentSum = Math.max(num, currentSum + num);
  maxSum = Math.max(maxSum, currentSum);
}`}
/>

| 关注点     | Python                                       | TypeScript                                      |
| ---------- | -------------------------------------------- | ----------------------------------------------- |
| 遍历形态   | `for num in nums[1:]` 直接取值               | `for (let i = 1; ...)` 索引取值，需中转 `num`   |
| 极值函数   | 内置 `max(a, b)`                             | `Math.max(a, b)`，需挂载命名空间                |
| 空数组判断 | `if not nums:` 真值测试                      | `if (nums.length === 0)` 显式长度比较           |
| 可变变量   | `max_sum` / `current_sum` 需更新，用普通赋值 | `let maxSum` / `let currentSum`，不可用 `const` |
| 切片开销   | `nums[1:]` 产生新列表（小常数，可接受）      | 索引循环无拷贝，心智对应"从 1 开始"             |
| 输出测试   | `print(...)`                                 | `console.log(...)`                              |

:::note
Python 切片 `nums[1:]` 会复制尾部，渐进仍为 O(n) 时间、O(n) 额外瞬时空间；极致场景可用 `range` 索引避免复制。TypeScript 索引循环天然无拷贝，两种形态在此题属于可互换的风格选择。
:::

## 常见错误分析

### 1. 初始化为 0，全负数组返回错误

```python
# 错误：全负时 0 大于任何子数组和
max_sum = current_sum = 0
```

输入 `[-3, -2, -5]` 时返回 0，但合法子数组至少含一个元素，正确答案为 `-2`。**改法**：固定以 `nums[0]` 初始化，空数组另行兜底。

### 2. 写成累加后取最大，丢失重开分支

```python
# 错误：从不重开，前段为负也被迫延续
current_sum += num
max_sum = max(max_sum, current_sum)
```

输入 `[-2, 1]` 时，`current_sum` 从 -2 累加到 -1，全局最优停在 -1 而非 1。**改法**：转移必须含 `max(num, current_sum + num)` 的显式二选一。

### 3. TypeScript 里把累加变量声明为 `const`

```typescript
// 错误：strict 下重复赋值编译失败
const currentSum = nums[0];
currentSum = Math.max(num, currentSum + num);
```

`const` 绑定不可重新赋值，递推变量必须可变。**改法**：`currentSum` / `maxSum` 用 `let`，循环内中转的 `num` 用 `const`。Python 无此编译约束，迁移时需养成按可变性选择声明关键字的习惯。

## 面试变体

1. **返回具体子数组**：除最大和外再返回起终下标。维护 `best_start` / `best_end` 与候选起点 `temp_start`：重开时更新 `temp_start`，刷新全局最优时同步区间。时间 O(n)、空间 O(1)。
2. **环形数组最大和**：子数组可跨首尾。答案为 `max(普通 Kadane, 总和 - 最小子数组和)`，全负时退化为普通 Kadane。两次线性扫描，时间 O(n)、空间 O(1)。
3. **至少含 k 个元素**：子数组长度下限为 `k`。先算前 `k` 个和作基，再滑窗维护，时间 O(n)、空间 O(1)，注意窗口与 Kadane 决策的叠加顺序。
4. **打家劫舍式不相邻约束**：相邻元素不可同选时转移变为 `dp[i] = max(dp[i-1], dp[i-2] + num)`。同样是线性 DP，但状态含义从"以 i 结尾"变为"前 i 个的最优"，可对照[打家劫舍](../house-robber/)与[最长递增子序列](../longest-increasing-subsequence/)体会状态定义的差别。

## 面试追问

- `max(num, current_sum + num)` 等价于什么条件分支？（等价于 `current_sum < 0` 时重开，否则延续；`max` 写法把分支压缩为单表达式。）
- 为何全局更新必须在局部更新之后？（`max_sum` 依赖本轮最新的 `current_sum`；顺序颠倒会用上一轮局部值更新全局，导致滞后一拍。）
- 分治做法的跨中点合并为何是 O(n)？（需向左右各扩展一次求跨中点最优，合并线性，递推式为 `T(n) = 2T(n/2) + O(n)`，解得 O(n log n)。）
- 全负数组为何能自然通过？（初始化锚定首元素后，`max` 转移保证 `current_sum` 始终对应某个真实子数组，不存在"空子数组和为 0"的幽灵候选项。）
