## 问题描述

沿街有多间房屋，每间藏有非负整数现金。相邻房屋装有连通的防盗系统，若同一晚闯入两间相邻房屋则自动报警。给定数组 `nums`，求在不触发报警的前提下能够偷窃到的最高金额。

**示例 1**

```text
输入：nums = [1, 2, 3, 1]
输出：4
解释：偷第 0 间和第 2 间，1 + 3 = 4
```

**示例 2**

```text
输入：nums = [2, 7, 9, 3, 1]
输出：12
解释：偷第 0、2、4 间，2 + 9 + 1 = 12
```

**约束条件**

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 400`

**边界情况**：空数组返回 `0`；仅一间时只能偷该间；连续两间只能取较大者。金额非负保证递推单调，若允许负数则状态定义需要调整。

## 暴力解与瓶颈

朴素想法是枚举全部子集并检查相邻约束：

```python
def rob_brute(nums: list[int]) -> int:
    best = 0
    n = len(nums)
    for mask in range(1 << n):
        total = 0
        ok = True
        for i in range(n):
            if mask >> i & 1:
                if i > 0 and (mask >> (i - 1) & 1):
                    ok = False
                    break
                total += nums[i]
        if ok:
            best = max(best, total)
    return best
```

子集总数为 2ⁿ，每个子集还要线性检查，时间复杂度 O(n·2ⁿ)。瓶颈在于大量前缀选择被重复评估：前 `i` 间房屋的最优值与后面房屋无关，符合最优子结构。优化方向是记录前缀最优值，递推代替枚举。

## 思路分析

动态规划。`dp[i]` 表示前 `i` 间房屋的最优金额，对第 `i` 间只有两种选择：不偷则继承 `dp[i-1]`，偷则为 `dp[i-2] + nums[i]`。转移方程为 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`。由于只依赖前两项，可压缩为两个变量滚动更新。

以 `nums = [2, 7, 9, 3, 1]` 为例：

| 下标 `i` | `nums[i]` | 不偷（`prev1`） | 偷（`prev2 + nums[i]`） | 当前最优 |
| -------- | --------- | --------------- | ---------------------- | -------- |
| 0 | 2 | — | — | 2 |
| 1 | 7 | 2 | 7 | 7 |
| 2 | 9 | 7 | 2 + 9 = 11 | 11 |
| 3 | 3 | 11 | 7 + 3 = 10 | 11 |
| 4 | 1 | 11 | 11 + 1 = 12 | 12 |

:::tip
关键细节是滚动变量的更新顺序：先用旧 `prev1`、`prev2` 算出 `current`，再把 `prev1` 移入 `prev2`、`current` 移入 `prev1`。顺序颠倒会导致 `prev2` 被提前覆盖，相当于偷了相邻房屋。
:::

## 复杂度分析

| 解法       | 时间复杂度 | 空间复杂度 | 说明                       |
| ---------- | ---------- | ---------- | -------------------------- |
| 子集枚举   | O(n·2ⁿ)    | O(1)       | 枚举全部掩码并检查相邻约束 |
| 动态规划   | O(n)       | O(n)       | 完整 `dp` 数组保留全部前缀 |
| 滚动 DP    | O(n)       | O(1)       | 仅保留前两项，逻辑等价     |

## 双语实现

  <TabItem label="Python" icon="seti:python">
    ```python
    # 打家劫舍 - Python 实现
    # 时间复杂度: O(n), 空间复杂度: O(1)
    # 核心思路: dp[i] = max(dp[i-1], dp[i-2] + nums[i])
    def rob(nums: list[int]) -> int:
        # 空数组直接返回 0
        if not nums:
            return 0
        # 仅一间时只能偷该间
        if len(nums) == 1:
            return nums[0]

        # prev2 对应 dp[i-2]，prev1 对应 dp[i-1]
        prev2 = nums[0]
        prev1 = max(nums[0], nums[1])

        # 从第 3 间开始递推
        for i in range(2, len(nums)):
            # 不偷当前 vs 偷当前取较大者
            current = max(prev1, prev2 + nums[i])
            # 向前滚动一步
            prev2 = prev1
            prev1 = current

        return prev1

    # 测试用例
    print(rob([1, 2, 3, 1]))  # 4
    print(rob([2, 7, 9, 3, 1]))  # 12
    print(rob([2, 1, 1, 2]))  # 4
    ```

    // 打家劫舍 - TypeScript 实现
    // 时间复杂度: O(n), 空间复杂度: O(1)
    // 核心思路: dp[i] = max(dp[i-1], dp[i-2] + nums[i])
    function rob(nums: number[]): number {

        // 向前滚动一步
        prev2 = prev1;
        prev1 = current;
      }

      return prev1;
    }

    console.log(rob([1, 2, 3, 1])); // 4
    console.log(rob([2, 7, 9, 3, 1])); // 12
    console.log(rob([2, 1, 1, 2])); // 4

## Python 与 TypeScript 差异点评

两份代码递推完全一致，差异集中在空值判断与最大值函数的表达上：

<CodeCompare
  py={`# 空数组与单元素守卫
if not nums:
    return 0
if len(nums) == 1:
    return nums[0]`}
  ts={`// 空数组与单元素守卫
if (nums.length === 0) {
  return 0;
}
if (nums.length === 1) {
  return nums[0];
}`}
/>

| 关注点   | Python                          | TypeScript                              |
| -------- | ------------------------------- | --------------------------------------- |
| 空数组判断 | `if not nums`，空列表为假值     | `nums.length === 0`，需显式比较长度     |
| 取最大值 | 内置 `max(a, b)`                | `Math.max(a, b)`                        |
| 可变绑定 | `prev2`、`prev1` 按需重赋值即可 | `let` 声明可变变量，`const` 声明 `current` |
| 索引访问 | `nums[0]` 越界抛 `IndexError`   | `nums[0]` 越界得 `undefined`，类型为 `number` 需留心 |
| 遍历写法 | `range(2, len(nums))`           | `for (let i = 2; i < nums.length; i++)` |
| 输出测试 | `print(...)`                    | `console.log(...)`                      |

:::note
TypeScript 开启 `noUncheckedIndexedAccess` 后，`nums[0]` 类型为 `number | undefined`。本题守卫已排除空数组与单元素越界，后续索引访问安全；若工程配置更严格，可用局部变量收窄或非空断言并附依据。
:::

## 常见错误分析

### 1. 初始化漏掉第二间房屋

```python
# 错误：prev1 初始化不当
prev2 = 0
prev1 = nums[0]
for i in range(1, len(nums)):
    ...
```

当 `nums = [2, 7]` 时正确值为 `7`，错误版本在首轮比较的是 `max(2, 0 + 7)` 侥幸正确，但在更长输入中语义混乱。**改法**：按正解显式处理 `prev1 = max(nums[0], nums[1])`，循环从索引 `2` 开始。

### 2. 滚动更新顺序写反

```python
# 错误：prev2 被提前覆盖
prev2 = prev1
current = max(prev1, prev2 + nums[i])
```

此时 `prev2 + nums[i]` 实际等于 `prev1 + nums[i]`，相当于允许偷相邻房屋。**改法**：先算 `current` 再滚动两个变量。

### 3. TypeScript 里混用 `const` 与重赋值

```typescript
// 错误：strict 下编译不通过
const prev2 = nums[0];
prev2 = prev1; // Cannot assign to 'prev2' because it is a constant.
```

滚动变量必须重赋值，应声明为 `let`；循环内的 `current` 不再修改，声明为 `const`。Python 无 `const` 概念，迁移时需要补上可变性心智。

## 面试变体

1. **环形街道**：首尾房屋也相邻，首尾不能同偷。拆成"偷首不偷尾"与"偷尾不偷首"两个线性问题各算一次，取较大者。时间 O(n)、空间 O(1)。
2. **输出方案**：除最高金额外还要返回被偷房屋下标。保留完整 `dp` 数组并记录每个位置是否选择，结束后从末尾回溯。时间 O(n)、空间 O(n)，回溯部分 O(n)。
3. **最大子数组对照**：若约束从"不能相邻"改为"必须连续"，问题退化为 Kadane 算法（详见[最大子数组和](../maximum-subarray/)）。DP 入门的线性递推对照可参考[爬楼梯](../climbing-stairs/)。

## 面试追问

- 为什么 `dp[i]` 只依赖前两项？能否只用一个变量？（偷当前必须跳过前一间，最远只需看 `i-2`；一个变量会丢失 `dp[i-1]`，无法表达"不偷当前"的分支。）
- 输入存在负数时转移方程还成立吗？（金额非负保证前缀最优单调；若可为负，"偷"分支可能不如空集，需要调整初始值与语义。）
- 如何在 O(1) 空间下同时返回被偷下标？（滚动值无法回溯，必须保留选择记录或完整 `dp` 数组，空间回到 O(n)。）
