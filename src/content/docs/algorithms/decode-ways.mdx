## 问题描述

`A-Z` 分别映射为 `1-26`。给定只含数字的非空字符串 `s`，将其分组并映射回字母，求不同的解码方式总数。`0` 不能单独解码，只能作为 `10` 或 `20` 的一部分。

**示例 1**

```text
输入：s = "12"
输出：2
解释："AB"(1,2) 或 "L"(12)
```

**示例 2**

```text
输入：s = "226"
输出：3
解释："BBF"(2,2,6)、"BZ"(2,26)、"VF"(22,6)
```

**约束条件**

- `1 <= s.length <= 100`
- `s` 仅包含数字字符

**边界情况**：以 `0` 开头直接返回 `0`；`10`、`20` 中 `0` 必须与前一字符绑定；`27-99` 不可两两组合；`01-09` 因前导零不可组合。递推起点把空串视为 `1` 种方式，这是组合计数的常见空积约定。

## 暴力解与瓶颈

朴素想法是对每个位置尝试切一刀或两刀，递归计数：

```python
def decodings_brute(s: str, i: int = 0) -> int:
    if i == len(s):
        return 1
    if s[i] == '0':
        return 0
    total = decodings_brute(s, i + 1)
    if i + 1 < len(s) and 10 <= int(s[i:i + 2]) <= 26:
        total += decodings_brute(s, i + 2)
    return total
```

后缀子问题被大量重复求解，例如长串中靠后的位置会被指数条路径反复访问，时间复杂度 O(2ⁿ)。瓶颈在于位置 `i` 的答案只依赖 `i+1` 与 `i+2` 的答案，却每次都重新递归。优化方向是倒序或正序记录每个前缀的答案，递推代替递归。

## 思路分析

动态规划。`dp[i]` 表示前 `i` 个字符的解码数。处理第 `i` 个字符时分两路：若 `s[i-1]` 非零可单独解码，贡献 `dp[i-1]`；若后两位在 `10-26` 范围内可组合解码，贡献 `dp[i-2]`。由于只依赖前两项，可压缩为 `prev1`、`prev2` 滚动更新。

以 `s = "226"` 为例（`dp[0] = 1`，`dp[1] = 1`）：

| 前缀 | 当前字符 | 单独解码 | 组合解码 | `dp` |
| ---- | -------- | -------- | -------- | ---- |
| `"2"` | `2` | — | — | 1 |
| `"22"` | 第二个 `2` | `2` 合法，+1 | `22` 合法，+1 | 2 |
| `"226"` | `6` | `6` 合法，+2 | `26` 合法，+1 | 3 |

:::tip
关键细节是两路条件相互独立，必须分别判断后累加。`0` 单独解码恒非法，`10` 与 `20` 单独看非法但组合合法，`30` 两路皆非法会导致 `current = 0` 并向后传播。
:::

## 复杂度分析

| 解法       | 时间复杂度 | 空间复杂度 | 说明                     |
| ---------- | ---------- | ---------- | ------------------------ |
| 递归暴力   | O(2ⁿ)      | O(n)       | 后缀子问题重复求解，栈深 n |
| 完整 DP    | O(n)       | O(n)       | 保留全部前缀答案         |
| 滚动 DP    | O(n)       | O(1)       | 仅保留前两项，逻辑等价   |

    ```python
    # 解码方法 - Python 实现
    # 时间复杂度: O(n), 空间复杂度: O(1)
    # 核心思路: dp[i] = 单独解码贡献 + 组合解码贡献
    def num_decodings(s: str) -> int:
        # 空串或首字符为 0 时无解
        if not s or s[0] == '0':
            return 0

        n = len(s)
        # prev2 为 dp[0]，空串视为 1 种方式
        prev2 = 1
        # prev1 为 dp[1]，首字符已确认非零
        prev1 = 1

        for i in range(1, n):
            current = 0
            # 单独解码 s[i]，仅 1-9 合法
            if '1' <= s[i] <= '9':
                current += prev1
            # 组合解码 s[i-1:i+1]，仅 10-26 合法
            two_digit = int(s[i - 1:i + 1])
            if 10 <= two_digit <= 26:
                current += prev2
            # 向前滚动一步
            prev2 = prev1
            prev1 = current

        return prev1

    # 测试用例
    print(num_decodings("12"))  # 2
    print(num_decodings("226"))  # 3
    print(num_decodings("06"))  # 0
    ```

    ```typescript
    // 解码方法 - TypeScript 实现
    // 时间复杂度: O(n), 空间复杂度: O(1)
    // 核心思路: dp[i] = 单独解码贡献 + 组合解码贡献
    function numDecodings(s: string): number {
      // 空串或首字符为 0 时无解
      if (s.length === 0 || s[0] === "0") {
        return 0;
      }

      const n = s.length;
      // prev2 为 dp[0]，空串视为 1 种方式
      let prev2 = 1;
      // prev1 为 dp[1]，首字符已确认非零
      let prev1 = 1;

      for (let i = 1; i < n; i++) {
        let current = 0;
        // 单独解码 s[i]，仅 1-9 合法
        if (s[i] >= "1" && s[i] <= "9") {
          current += prev1;
        }
        // 组合解码 s.substring(i - 1, i + 1)，仅 10-26 合法
        const twoDigit = parseInt(s.substring(i - 1, i + 1), 10);
        if (twoDigit >= 10 && twoDigit <= 26) {
          current += prev2;
        }
        // 向前滚动一步
        prev2 = prev1;
        prev1 = current;
      }

      return prev1;
    }

    // 测试用例
    console.log(numDecodings("12")); // 2
    console.log(numDecodings("226")); // 3
    console.log(numDecodings("06")); // 0
    ```

## Python 与 TypeScript 差异点评

两份代码递推完全一致，差异集中在字符比较与子串转整数的表达上：

```python
# 切片取两位并转整数
two_digit = int(s[i - 1:i + 1])
if 10 <= two_digit <= 26:
    current += prev2
```

```typescript
// substring 取两位并转整数
const twoDigit = parseInt(s.substring(i - 1, i + 1), 10);
if (twoDigit >= 10 && twoDigit <= 26) {
  current += prev2;
}
```

| 关注点     | Python                              | TypeScript                                      |
| ---------- | ----------------------------------- | ----------------------------------------------- |
| 字符比较   | `'1' <= s[i] <= '9'` 支持链式比较   | `s[i] >= "1" && s[i] <= "9"` 需显式逻辑与       |
| 子串提取   | 切片 `s[i-1:i+1]`，左闭右开         | `s.substring(i - 1, i + 1)`，语义相同           |
| 字符串转整数 | `int(...)`，非法抛异常            | `parseInt(..., 10)`，需显式指定十进制基数       |
| 范围判断   | `10 <= x <= 26` 链式写法            | `x >= 10 && x <= 26` 分段写法                   |
| 空串判断   | `if not s` 假值判断                 | `s.length === 0` 显式比较                       |
| 输出测试   | `print(...)`                        | `console.log(...)`                              |

:::note
`parseInt` 必须显式传入基数 `10`，否则历史语义中前导零可能触发八进制解析。Python 切片越界自动截断而 `substring` 越界同样截断，两者在循环范围内行为一致，但都依赖 `i` 的取值合法。
:::

## 常见错误分析

### 1. 两位数组件范围写成 `1-26`

```python
# 错误：把 01-09 也当作合法组合
if 1 <= two_digit <= 26:
    current += prev2
```

`int("01")` 等于 `1`，数值检查会放行前导零。**改法**：下界必须为 `10`，`01-09` 因前导零非法，`27-99` 因超出字母表非法。

### 2. 忘记处理首字符为 `0`

```python
# 错误：缺少守卫，dp 初始值不再成立
prev2 = 1
prev1 = 1
```

输入 `"06"` 应返回 `0`。若缺少 `s[0] == '0'` 守卫，`prev1 = 1` 的前提（首字符可单独解码）即不成立。**改法**：循环前先拦截空串与首零。

### 3. TypeScript 字符串索引的 `strict` 坑

```typescript
// 错误：开启 noUncheckedIndexedAccess 后编译不通过
if (s[i] >= "1") { ... } // s[i] 类型为 string | undefined
```

字符串索引越界时类型带 `undefined`，直接比较会被拦截。**改法**：本题循环保证 `i < n`，索引安全；若配置严格，可先用局部变量收窄或断言并附依据。Python 越界抛 `IndexError`，问题暴露在运行时而非编译期。

## 面试变体

1. **含通配符解码**：`s` 中出现 `*` 可表示 `1-9`。单独解码分支按 9 种展开，组合分支按前一字符分类讨论（`1*` 有 9 种，`2*` 有 6 种）。时间 O(n)、空间 O(1)，注意取模要求。
2. **返回具体方案**：除计数外还要恢复一种解码串。保留完整 `dp` 并记录每个位置的转移来源，结束后回溯。时间 O(n)、空间 O(n)。
3. **字符串 DP 对照**：本问题与[单词拆分](../word-break/) 同属字符串前缀 DP，只是词典从固定映射变为可复用单词集合；线性递推的入门对照可参考[爬楼梯](../climbing-stairs/)。

## 面试追问

- 为什么 `dp[0]` 要定义为 `1` 而不是 `0`？（空串是组合计数的空积起点，`"10"` 的组合分支需要 `dp[0]` 贡献 1，否则合法组合会被清零。）
- 输入 `"100"` 的递推过程为何归零？在哪一步归零？（`i = 2` 时 `0` 不可单独解码且 `00` 非法，`current = 0`，后续无法恢复。）
- 长度为 1 的输入为何不需要进循环？（`prev1` 已是 `dp[1]` 答案，循环仅处理 `i >= 1` 的扩展；`"0"` 由守卫提前拦截。）
