## 自测清单

完成以下检查项，就可以开始用 TypeScript 写真实项目了：

- [ ] 我能解释同一段逻辑在 Python 和 TypeScript 的类型差异
- [ ] 我能为函数参数与返回值写出清晰类型
- [ ] 我能读懂并改写 Promise / async 代码
- [ ] 我能熟练使用类型推断和类型断言
- [ ] 我能处理可选值和默认值
- [ ] 我能区分 interface 和 type，并知道什么时候用哪个

## 练习建议

1. **先学习再测验**：测验不是用来探索新知识的，是用来验证的
2. **错题回到原文**：每道题的解析都能指回对应课程，别只看对错
3. **刻意对比**：写算法时先想 Python 怎么写，再对照 TypeScript 实现的差异
4. **建立自己的对照表**：把反复踩的坑记下来，比任何速查表都好用
