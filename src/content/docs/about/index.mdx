这是一个面向 Python 开发者的 TypeScript 学习站点，采用内容优先的静态文档架构。

## 项目目标

- 用并排对照降低语言迁移成本
- 用算法题提升实战与面试能力
- 用可维护的静态站点保证长期可迭代

## 内容是怎么组织的

站点按你要做的事分成四块，而不是按文件类型分：

| 板块 | 内容 | 什么时候来 |
| --- | --- | --- |
| 课程 | 四条路径共 22 节课 | 系统地学 |
| 实战 | 36 道算法题、编程测验 | 练手和检验 |
| 参考 | 对照手册、标签与难度索引 | 卡住时查 |
| 我的 | 学习进度与收藏 | 看自己走到哪了 |

课程顺序是人工排定的教学顺序，不按字母序。新增课程时把 slug 写进 `src/lib/curriculum.ts`，
侧边栏、分页、首页进度会自动跟随，不需要分别改四处。

## 参与贡献

1. 阅读 `CONTRIBUTING.md`
2. 保持「一个可验证功能切片一个提交」
3. 提交前运行 `npm run check`

## 技术栈

Astro + Starlight，纯静态，部署在 GitHub Pages。交互部分（进度、收藏、测验）不依赖后端，
数据存在浏览器本地存储里。
