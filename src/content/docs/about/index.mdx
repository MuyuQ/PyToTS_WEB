这是一个面向 Python 开发者的 TypeScript 学习站点，采用内容优先的静态文档架构。

## 适合谁

- **Python 开发者**：想系统迁移到 TypeScript，降低语言切换成本
- **面试准备者**：需要掌握 TS 核心差异、算法实战与面试高频点
- **团队技术负责人**：需要标准化的 Python→TS 迁移培训资料
- **自学者**：想按科学路径从零建立 TS 类型思维

## 项目目标

- 用并排对照降低语言迁移成本（Python 代码左、TS 代码右，差异一眼可见）
- 用算法题提升实战与面试能力（36 道双语题、复杂度分析、面试变体）
- 用可维护的静态站点保证长期可迭代（Astro + Starlight，纯静态，零后端）

## 内容组织：按"你要做的事"分四块

| 板块     | 内容                                      | 什么时候来           |
| -------- | ----------------------------------------- | -------------------- |
| **课程** | 四条路径共 22 节课（准备/基础/迁移/进阶） | 系统地学，按顺序走完 |
| **实战** | 36 道算法题、编程测验                     | 练手、检验、面试冲刺 |
| **参考** | 对照手册、标签索引、难度索引              | 卡住时查、碎片查阅   |
| **我的** | 学习进度、收藏书签                        | 看自己走到哪了       |

课程顺序是人工排定的教学顺序，不按字母序。新增课程时把 slug 写进 `src/lib/curriculum.ts`，侧边栏、分页、首页进度会自动跟随，不需要分别改四处。

## 怎么用

1. **新手**：从[学习路径总览](../paths/)按顺序走四条路径
2. **有基础**：去[迁移路径](../paths/migration/)或[进阶路径](../paths/advanced/)补差异
3. **碎片查阅**：卡语法去[手册](../handbook/cheat-sheet/)查对照表
4. **实战验证**：去[练习与自测](../practice/)做自测清单，去[测验页](../practice/quiz/)分模块测验
5. **面试冲刺**：去[算法题库](../algorithms/)按难度/标签筛选，看双语实现与面试变体

## 贡献指南

1. 阅读 [`CONTRIBUTING.md`](https://github.com/MuyuQ/PyToTS_WEB/blob/main/CONTRIBUTING.md)
2. 保持「一个可验证功能切片一个提交」
3. 提交前运行 `npm run check`（lint + typecheck + test + build + linkcheck）

## 技术栈

- **框架**：Astro + Starlight（文档站专用主题）
- **部署**：GitHub Pages（纯静态，零服务器成本）
- **交互**：进度、收藏、测验全部浏览器端 `localStorage`，无后端依赖
- **样式**：CSS 变量 + Starlight 主题 token，暗/亮主题自适应
- **搜索**：Pagefind 离线全文搜索
- **链接检查**：构建产物级 `linkcheck` 防子路径 404
